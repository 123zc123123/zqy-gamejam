斗蛐蛐 · 育虫盘（战斗之外，怎么获得蛐蛐）

这不是对战原型。对战在 prototype-v4；这边只负责把成虫养出来、升品质、换钱。

怎么打开
1. 用浏览器直接打开本目录的 index.html 即可（不需要 node）
2. 手机竖屏更接近真机；电脑也可以点

操作
- 左下角「虫卵」是消耗道具。右下角红点是堆叠数量
- 点一次虫卵，棋盘上就多一枚卵（自动落到第一个空格）
- 两只相同阶段拖到一起就能合成；点一只再点另一只也可以
- 合成链：卵 + 卵 → 幼虫；幼虫 + 幼虫 → 中虫；中虫 + 中虫 → 成虫
- 点棋盘或虫笼里的虫子，弹出详情：占位战斗数值、性格说明，以及「入笼 / 出售」（笼里是「放回棋盘 / 出售」）
- 幼虫、中虫、成虫都能卖钱（虫卵不卖）。钱以后在外围买装饰，这版店还没开
- 拖虫笼里的成虫到棋盘空格，也可以放回去

成虫品质
- 两个中虫合成的那一下，先掷品质，再掷性格
- 破茧品质暂定：凡品 55% / 良品 28% / 精品 13% / 极品 4%
- 性格四选一，各 25%：好斗、沉稳、灵巧、耐久

成虫还能再合成（同品质）
- 凡 + 凡 → 良　72% 成功，失败化为 3 枚虫卵
- 良 + 良 → 精　48% 成功，失败化为 5 枚虫卵
- 精 + 精 → 极　25% 成功，失败化为 8 枚虫卵
- 极品封顶，不能再合成
- 成功时性格从父母里随机继承一个
- 卖是稳钱；合是赌更高品质去打架。越往上越亏期望、越像抽奖

售价（钱）
- 幼虫 3 / 中虫 8
- 凡品 20 / 良品 50 / 精品 140 / 极品 420

棋盘与虫笼
- 棋盘 5 行 × 3 列
- 虫笼固定 5 格，空格是竹笼；点回去就能再合成或卖掉

「再领一窝」是试玩补卵。「重置」清空棋盘、虫笼和钱，虫卵回到 16。
进度存在浏览器 localStorage，刷新不会丢。
