## 1. 一条链路

```
按住蓄力（A1 匀加速，仰角 θ）
  → 松手得到 Δv_x、Δv_y
  → 空中走抛物线：vx 不变，ty = 2 Δv_y / g
  → 落地后沿瞄准方向匀减速到 0
```

要的手感：**水平速度先不变、后减速；不变的时间占总时间的比例是定值**，跟蓄了多久无关。

没有第二套表现速度，也没有 `jumpT` / `hitT`。碰撞见 §3。

## 2. 主动碰撞前：蓄力、飞出、保底

### 2.1 蓄力：水平速度、竖直速度

按住时水平匀加速。仰角 $\theta$ 是配置项，不是玩家瞄准（地面朝向仍是 360°）。质量和 $\mu$ 不进蓄力。

$$
\Delta v_x = A_1\,\Delta t,\qquad
\Delta v_y = A_1\tan\theta\,\Delta t
$$

所以 $\Delta v_y / \Delta v_x = \tan\theta$，出手方向就是 $\theta$。

$A_1$、$\theta$ 都是配置项。$\theta$ 面板键 `theta`。$\Delta t$ 钳在 $\bigl[0,\, T_{\max}\bigr]$：蓄满后可以一直按着，速度不再涨，也不会自动跳出。

- 按住就开始计时，`chargeT` 和真实时间 1:1。
- 地面方向 360° 可改；松手后方向锁定，空中不能转。
- 必须停稳才能蓄。还在飞 / 还在滑时按住，只挂起；停稳后才开始计。
- 停稳判定：已落地且水平速度 $< 0.06$。
- 蓄力中被撞：进度清零，不锁操作。手指还按着，停稳后从 0 再蓄。
- 自己跳落地后可以立刻再蓄。

| 项         | 默认   | 含义                                            |
| ---------- | ------ | ----------------------------------------------- |
| $A_1$    | 23     | 水平蓄力加速度；面板键`vRate`                 |
| $\theta$ | 45°   | 仰角；配置项，面板键`theta`；匀速占比见 §2.2 |
| `T_max`  | 0.55 s | $\Delta t$ 封顶                               |

默认蓄满：$\Delta v_x = 23 \times 0.55 = 12.65$，$\Delta v_y = 12.65$（$\theta=45°$）。短于保底的按，被 §2.3 托住。

### 2.2 飞出：抛物线 + 直线匀减速

两段接在一起。水平速度先保持 $\Delta v_x$，落地后再匀减速。

#### 2.2.1 过程速度

**抛物线（空中）**

只受重力。$v_x$ 不变，$v_y$ 按 $g$ 掉。平地起平地落：

$$
t_y = \frac{2\Delta v_y}{g} = \frac{2 A_1\tan\theta\,\Delta t}{g}
$$

**直线匀减速（落地后）**

落地时水平速度仍是 $\Delta v_x$。贴地加速度 $a = \mu g$：

$$
t_{\text{地}} = \frac{\Delta v_x}{\mu g} = \frac{A_1\,\Delta t}{\mu g}
$$

水平速度：

$$
v_x(t) =
\begin{cases}
\Delta v_x & 0 \le t < t_y \\[4pt]
\Delta v_x - \mu g\,(t - t_y) & t_y \le t \le t_y + t_{\text{地}}
\end{cases}
$$

**匀速占比是定值**

$$
k = \frac{t_y}{t_y + t_{\text{地}}} = \frac{2\mu\tan\theta}{2\mu\tan\theta + 1}
$$

$k$ 与 $A_1$、$\Delta t$、$g$ 无关。短按和蓄满，先匀速、后减速的时间比例一样。改 $\mu$ 或 $\theta$ 才会改这个比例。

- $\mu$ 很大：$t_{\text{地}}\to 0$，$k\to 1$，基本整段都是空中匀速。
- $\mu$ 很小：$t_{\text{地}}\to\infty$，$k\to 0$，基本整段都是落地后减速。

默认 $\mu=0.5$，$\theta=45°$：$k = 1/2$。蓄满 $t_y \approx t_{\text{地}} \approx 1.41\,\mathrm{s}$，全程约 $2.81\,\mathrm{s}$，一半时间 $v_x$ 不减速。

| 项         | 默认 | 含义                                              |
| ---------- | ---- | ------------------------------------------------- |
| $\theta$ | 45° | 仰角；配置项，面板键`theta`；与 μ 一起定 $k$ |
| μ         | 0.5  | 落地摩擦系数；面板键`mu`                        |
| $g$      | 18   | 重力；面板键`g`                                 |

#### 2.2.2 过程距离与总距离

空中水平位移、落地滑行、全程和最高点，都只由 $A_1$、$\Delta t$ 和配置项写出：

$$
\begin{aligned}
D_{\text{空}} &= \frac{2 A_1^{2}\tan\theta\,(\Delta t)^{2}}{g} \\[6pt]
D_{\text{地}} &= \frac{A_1^{2}\,(\Delta t)^{2}}{2\mu g} \\[6pt]
D &= D_{\text{空}} + D_{\text{地}} = \frac{A_1^{2}\,(\Delta t)^{2}}{g}\left(2\tan\theta + \frac{1}{2\mu}\right) \\[6pt]
H &= \frac{A_1^{2}\tan^{2}\theta\,(\Delta t)^{2}}{2g}
\end{aligned}
$$

$H$ 进位置、进观感。$g$ 同时缩两段时长、两段距离和高度，不改 $k$。

默认蓄满：

|            | 时长                                       | 水平位移                      | 高度              |
| ---------- | ------------------------------------------ | ----------------------------- | ----------------- |
| 空中抛物   | $t_y \approx 1.41\,\mathrm{s}$           | $D_{\text{空}}\approx 17.8$ | $H\approx 4.45$ |
| 落地匀减速 | $t_{\text{地}} \approx 1.41\,\mathrm{s}$ | $D_{\text{地}}\approx 8.89$ | $0$             |
| 全程       | $\approx 2.81\,\mathrm{s}$               | $D\approx 26.7$             | —                |

#### 2.2.3 总时长

$$
T = t_y + t_{\text{地}} = \frac{A_1\,\Delta t}{g}\left(2\tan\theta + \frac{1}{\mu}\right)
$$

$T$ 不是旋钮。蓄得越满，空中和落地都更久，比例仍是 $k$。默认蓄满 $T \approx 2.81\,\mathrm{s}$。

$g$ 放大则 $T$ 变短，不改 $k$。

### 2.3 保底限制

1. 起跳蓄力时间下限 `T_min`：未满松手是否取消。默认配置 0，让玩家只要按了就能跳。`T_min > 0` 时，松手未满则取消、不跳。
2. 保底水平总位移 `dMin` 与最小 $\Delta v_x$
   1. 蓄力很短时，玩家应该可见移动。
   2. `dMin` 与 $(\Delta v_x)_{\min}$ 能相互确定：

$$
(\Delta v_x)_{\min} = \sqrt{\frac{\texttt{dMin}\cdot g}{2\tan\theta + 1/(2\mu)}}
$$

3. 从表现出发，把 `dMin` 作为配置项。
4. 实际出手：$\Delta v_x = \max\bigl((\Delta v_x)_{\min},\, A_1\Delta t\bigr)$，$\Delta v_y = \Delta v_x\tan\theta$。

| 项        | 默认 | 含义                                     |
| --------- | ---- | ---------------------------------------- |
| `T_min` | 0    | 未满松手是否取消                         |
| `dMin`  | 1.2  | 短按保底位移（内部再反推成$v_{\min}$） |

默认 $\theta=45°$ 算出来：

- $(\Delta v_x)_{\min} = \sqrt{1.2\times 18 / 3} \approx 2.68$
- 蓄到保底要 $2.68 / 23 \approx 0.12\,\mathrm{s}$
- **短于 0.12 s 的按，全是同一档：水平总位移 1.2，匀速占比仍是 $1/2$**

## 3. 碰撞

撞人用当前 $v$。换速见 §3.2。撞后贴地用哪档 $\mu$，见 §3.3.2。

### 3.1 判定

- 圆 vs 圆，半径 `r`，只看地面 XZ，不管高度。
- 每帧拆 `MOVE_SUBSTEPS = 6` 次：先位移，再碰撞。
- 当前帧已经重叠：先按质量比推开，再结算速度。
- 当前帧没重叠、但这一步相对运动扫过对方：用线段扫圆补一次，把双方拨回接触点再结算。
- 没有罐壁。地面投影超出圆角矩形有效区 = 出局。

### 3.2 撞击：弹性碰撞模型

撞人用的就是屏幕上正在飞的那套速度：当前 $v$。没有「记下的起点速度」、没有尾段 fade 窗口。

- 刚起跳：全力，等于松手时的 $v$
- 滑到一半：大约一半
- 已经停稳：入射 = 0，等于撞静止物

站桩被撞、蓄力被撞，入射都是 0。越接近停稳，这一撞越轻。

完全弹性，$e = 1$。只换法线方向，切线不换：

$$
\begin{aligned}
v_n &= \text{相对速度在法线上的分量} \\
&\quad \text{若 } v_n \ge 0\text{：已经在分离，不算撞} \\[8pt]
j &= -\frac{(1+e)\,v_n}{\dfrac{1}{m_A} + \dfrac{1}{m_B}} \\[12pt]
\mathbf{v}'_A &= \mathbf{v}_A - \frac{j}{m_A}\,\mathbf{n} \\[6pt]
\mathbf{v}'_B &= \mathbf{v}_B + \frac{j}{m_B}\,\mathbf{n}
\end{aligned}
$$

质量大的少飞，小的多飞。等质量正撞 ≈ 交换法向速度。重叠推开也按质量比：轻的多让、重的少让。

`m` 只在这一步生效：不影响自己起跳的初始速度，只影响对撞之后谁飞得远。

**撞完立刻：**

1. 打断双方蓄力（进度清零，不锁操作）
2. 取消跳弧，贴地
3. 双方带着新速度贴地再滑。距离公式同 §3.3.1，每人自己的 $\mu$ 按 §3.3.2 分档。没有单独的被撞时长
4. 记下 `lastHitId`。对方出圈时击杀方 +1 成长，见 [道具系统](道具系统_develop_v0.md)

### 3.3 撞后滑行

#### 3.3.1 基础模型

和自己跳落地后同一套匀减速。这里的 $\mu$ 先按 §2.2 的地面摩擦；每人实际用哪一档，见 §3.3.2。

$$
\begin{aligned}
D_{\text{被撞}} &= \frac{v_{\text{撞后}}^{2}}{2\mu g} \\[6pt]
T_{\text{被撞}} &= \frac{v_{\text{撞后}}}{\mu g}
\end{aligned}
$$

默认例子（等质量、满蓄正撞站桩、默认态 $\mu=0.5$）：进攻方几乎停住，防守方吃走 12.65，滑出 $\approx 8.89$，约 $1.41\,\mathrm{s}$。侧撞只吃法向分量，距离按那个分量的平方掉。

| 项          | 默认 | 含义                       |
| ----------- | ---- | -------------------------- |
| `m`       | 1    | 对撞分速度；吃心后同比变大 |
| `ELASTIC` | 1    | 恢复系数，完全弹性         |

#### 3.3.2 抵抗能力

撞后每人单独判一档。这一档只改自己这一段贴地滑多远，不改对方，也不改自己下次起跳。

**1. 要分出的三种受撞**

玩家读得懂的只有三句话：这次是我在撞人、这次是普通被撞、这次我站不稳。对应三档，都只改摩擦系数：

| 档         | 玩家该感到什么           | μ                         |
| ---------- | ------------------------ | -------------------------- |
| 在控制之内 | 我比他快，还握着这次撞击 | μ × λ_control，刹得更死 |
| 默认态     | 我被压了一下，但还扛得住 | 不变                       |
| 失衡态     | 对方已经压过我现在能扛的 | μ × λ_slip，滑得更远    |

这三档是为下面这些情形准备的：

（1） **我比对方快（或一样快）。**
   这是我主动撞过去，应进「在控制之内」，能快点停住，接着出手。只比撞击方向上的速度，不看体重。对方再重，哪怕是胖子，只要我更快，我就可控。胖子不会因为沉就变成墙。
（2） **我几乎停了——哪怕我更重。**
   应进「失衡态」。轻的人看到胖子在落地、在蓄力，应该去撞。站着重不该变成墙。
（3） **我一直很慢（点按），对方全力撞。**
   没投入力量，对位就该失衡。只靠体重不能买来抗性。
（4） **我还很快，只比对方慢一点；对方更重。**
   动量差会被体重拉开，但我还在场上。应尽量留在「默认态」，不要单靠体重差就失衡。
（5） **两边速度、动量都接近。**
   普通弹开，默认态。不要互相当墙，也不要无故多滑。

一句话：**停下来，应该比较容易被掀翻；还在冲，就应该比较难被掀翻。比对方快，则先算可控。**

**2. 判定方法**

每人先算自己此刻能扛多少，再看对方比自己多出来的那截动量。

**（1）抵抗 $R$**

- 抵抗先定两端，中间按初始速度线性走。
- 两端都写成自己满蓄动量的倍数。

  - $K_0$ 是站立端。
  - $K_1$ 是满速端。
- 面板拧的就是这两个无量纲比例。
- $V_0 = K_0 v_{\max}$ 是推出来的速度。
- 没有一颗和满蓄脱钩的裸速度。
- **静止且不蓄力。** 这一端只跟体重走。体重大应有一定抵抗，且不为 0。面板键 `rStand` 就是 $K_0$

  $$
  R_{\text{静}} = V_0 m = K_0\, m v_{\max}
  $$
- **满速撞击。** 这时抵抗应接近自己的速度，至少和速度相关。

  $$
  R_{\text{满}} = K_1 m v_{\max}
  $$

  - 写成自己满蓄动量的 $K_1$ 倍。
  - $v_{\max} = A_1 T_{\max}$（默认 $12.65$）。
  - 面板键 `rMax` 就是 $K_1$。
  - $K_1$ 先取 $1$ 附近：全速冲时，门槛大约就是自己这一份满蓄动量。
  - $K_1$ 不是 §2.2 的匀速占比 $k$。
- **中间。** 本次水平初始速度从 $0$ 走到 $v_{\max}$，抵抗从 $R_{\text{静}}$ 走到 $R_{\text{满}}$。

  $$
  \begin{aligned}
  R
  &= R_{\text{静}} + \frac{v_{\text{初}}}{v_{\max}}\,(R_{\text{满}} - R_{\text{静}}) \\
  &= K_0 m v_{\max} + \frac{v_{\text{初}}}{v_{\max}}\,(K_1 m v_{\max} - K_0 m v_{\max}) \\
  &= m\bigl[K_0(v_{\max}-v_{\text{初}}) + K_1 v_{\text{初}}\bigr]
  \end{aligned}
  $$

  - $v_{\text{初}}$ 是本次运动记下的水平初始速度，不用屏幕上的实时速度。
  - 自己跳：松手时的 $\Delta v_x$。
  - 刚被弹开：撞后那截水平速度，作为下一段滑行的初始速度。
  - 不到 $0$ 当 $0$。
  - 超过 $v_{\max}$ 当满速。
  - 停稳且没蓄力：$v_{\text{初}}$ 清零，回到站立端。
  - 停稳且正在蓄：走上面「静止且蓄力」，不看记下的 $v_{\text{初}}$。
  - 必须 $K_0 < K_1$（即 $V_0 < K_1 v_{\max}$），否则站着比飞着更抗。
  - 改 $A_1$ 或 $T_{\max}$ 会抬高或压低 $v_{\max}$。
  - 两端抵抗按同一比例跟着走，$K_0$ / $K_1$ 不用重配。
- **静止且蓄力。** 用中间同一套公式，但 $v_{\text{初}}$ 改成蓄力对应的出手速度再打折。

  $$
  v_{\text{初}} = \lambda_{\text{charge}}\,\Delta v_x,\qquad
  \Delta v_x = A_1\,\mathrm{clamp}(t,\,0,\,T_{\max})
  $$

  - 不走保底 $v_{\min}$。
  - 还没跳出去，不能按满额算。
  - 面板键 `rChargeScale` 就是 $\lambda_{\text{charge}}$。
  - $\lambda_{\text{charge}} < 1$ 是折扣；为 $0$ 则和没蓄一样。
  - 代入下面中间态的 $R$ 式。

**（2）被撞动量**

- 只看法向。
  - $\mathbf{n}$ 从自己指向对方。
  - 朝对方为正。
- 和 $R$ 比较的那截动量，速度用 $v_{\text{初}}$，不用此刻还剩多少。
  - 先沿当前朝向取出记下的水平初速度。
  - 再投到法向上，得到 $v_{\text{初},n}$。
  - 已经停稳、没有朝向：法向初速度为 $0$。
  - 站着蓄力只抬 $R$，不给自己加 $p_A$。

$$
p_A = m_A v_{A,\text{初},n},\qquad
p_B = m_B v_{B,\text{初},n},\qquad
\Delta p = p_B - p_A
$$

- $\Delta p$ 是对方比我多出来的（按初速度算的）动量。
  - 站着被撞时 $p_A = 0$，$\Delta p = p_B$。
  - 自己出发得越狠，$p_A$ 越大，差额越小。
  - 落地滑慢了也不改：仍按这段滑行开始时记下的 $v_{\text{初}}$。
- 分档：谁更快仍比撞击方向上的**当前**速度；过了这一关，再拿 $\Delta p$ 对 $R$。
  - 对 $A$（$B$ 对称）见下表。

| 档         | 何时                           | μ′             |
| ---------- | ------------------------------ | ---------------- |
| 在控制之内 | 当前$v_{A,n} \ge v_{B,n}$    | μ × λ_control |
| 默认态     | 当前更慢，且$\Delta p \le R$ | μ               |
| 失衡态     | 当前更慢，且$\Delta p > R$   | μ × λ_slip    |

- μ′ 只代入 §3.3.1。
  - λ_control、λ_slip 是乘在 μ 上的倍率。
  - 大于 1 刹得更死。
  - 小于 1 滑得更远。
  - 两边可以不同档。

**按默认配置**

$K_0 = \texttt{rStand} = 0.1$，所以 $V_0 = 0.1\,v_{\max} \approx 1.27$。$K_1 = 1$，$\lambda_{\text{charge}} = 0.5$，λ_control = 1.3，λ_slip = 0.65。默认 μ = 0.5 则三档 μ′ 是 0.65、0.5、0.325。

- 等质量、满蓄正撞站桩：站着的人进失衡，滑出 $\approx 13.7$（默认态是 $8.89$）。
- 等质量、对方满蓄、自己初始速度是满蓄一半：进默认态。
- 自己轻、只慢一点、对方约两倍重：容易刚过线进失衡。觉得太脆就加大 `rMax`。

## 4. 耐力（气力）

耐力按蓄力比例扣除。满蓄消耗记为 1，则 50% 蓄力消耗 0.5。蓄满不自动跳。

### 4.1 规则

- 最大耐力 `staminaMax = 5`。开局满。单位与满蓄消耗对齐：满蓄 = 1。
- 有效蓄力比例：

$$
q = \mathrm{clamp}\left(\frac{\mathrm{chargeT}}{T_{\max}},\,0,\,1\right)
$$

$T_{\max}$ 用当前有效值（含蓄力强化）。不走保底 $v_{\min}$：短于满蓄的按实际 `chargeT` 计。

- 真正起跳消耗 $C = \texttt{staminaCost}\cdot q$。默认 `staminaCost = 1`，故满蓄扣 1，半蓄扣 0.5。
- 消耗发生在确认起跳时；未满 `T_min` 的取消、蓄力中被撞打断，都不消耗。
- 耐力 $> 0$ 才能进入蓄力。蓄力进度封顶为当前耐力能负担的比例：

$$
q \le \frac{\mathrm{stamina}}{\texttt{staminaCost}}
$$

耐力不足 1 时仍可短蓄，不能蓄满。

- 落地且未蓄力时恢复（含滑行）；空中不恢复；蓄力期间暂停恢复。
- 身周圆环格数 `staminaSlots`（默认 5，范围 3–8）。满耐力最多连着满蓄 5 次；短蓄可以跳更多下。
- 小蟋蟀不读耐力。

```
按住输入
  → 检查：已落地、停稳、耐力 > 0
  → 进入蓄力（蓄力期间暂停恢复；进度不超过 stamina / staminaCost）
  → 松手且满足 T_min：扣 staminaCost × q，按原公式起跳
  → 松手未满足 T_min / 被撞打断：不扣耐力
```

- 蓄力中被撞：耐力保持不变，蓄力进度清零；手指仍按住时，必须等停稳且耐力 > 0 才能重新蓄力。
- 跳跃、碰撞、出圈、护盾、质量和抵抗分档均不因耐力改变；耐力只决定能否主动起跳、这次能蓄多大。
- 切换交互档保留耐力，不补满；重开对局才回满。
- 人机同一套消耗与恢复，无无限耐力。

### 4.2 表现

耐力为身周分格圆环，不占 HUD 主栏。一格对应一次满蓄。

- 环形填充比例 = `stamina / staminaMax`，从正上方起，按 `staminaSlots` 格走。
- 蓄力时圆环按本次预估消耗预览剩余；松手取消或被撞则回到扣之前。
- 充足青绿，低于 40% 琥珀，低于 20% 变红。只做提醒，不改规则。
- 双方圆环都可见，同一套分格。敌方圆环不参与碰撞 / 出圈。
- 耐力为 0 时圆环空着，不能蓄力。不弹出遮挡战场的文字。
- 圆环为表现层，不参与圆 vs 圆判定。

### 4.3 验收

玩家应能在不打开面板的情况下回答：**我还能不能跳、这次大概扣多少、什么时候开始回气**。

1. 满耐力连续满蓄 5 次后，不能再蓄。
2. 两次 50% 蓄力的消耗合计等于一次满蓄。
3. 蓄力过程中耐力不增长；松手取消或被撞打断不扣除。
4. 飞行中不恢复；落地滑行恢复，重新按住蓄力后立即暂停。
5. 耐力不足 1 时仍可短蓄，进度封顶为当前耐力；耐力 = 0 不能蓄力。
6. 圆环不参与出圈、重叠推开、碰撞半径。

| --- | --- | --- | --- | --- |
| 最大耐力 | `staminaMax` | 5 | 1–20 | 上限；不参与跳跃公式 |
| 满蓄耐力 | `staminaCost` | 1 | 0.1–5 | 满蓄真正起跳才扣；实际扣 = 该值 × q |
| 耐力恢复 | `staminaRegen` | 0.6 / s | 0–2 / s | 落地且未蓄力时恢复 |

v1 的 `jumpT` / `hitT` 在此版不存在。当前面板若还留着这两颗，v2 不读。

另外两颗不影响公式：`0.5× 慢放`、`速度线`。

拧一颗会带上另一颗：

1. **改 θ 或 μ**：匀速占比 $k = 2\mu\tan\theta/(2\mu\tan\theta+1)$ 会变。$\mu$ 很大则 $k\to 1$（几乎全程匀速）；$\mu$ 很小则 $k\to 0$（几乎全程减速）。只改 $\theta$：空中更久或更短，$v_x$ 不变。只改 $\mu$：落地刹得更猛或更肉，也改 $k$。
2. **改 g**：空中和落地的时长、位移一起缩放，$k$ 不变，出手 $v_x$ 不变。
3. **改 $A_1$ 或 $T_{\max}$**：出手快慢、两段位移、两段时长一起变；$k$ 仍不变。
4. **改 m**：对撞谁飞得远，也抬高或压低 $R$。
5. **改 `rStand` / `rMax`**：只改三档分界，不改自己跳的 $k$ 和 $D$。两颗都是相对 $v_{\max}$ 的倍数（`rStand` $= K_0$，$V_0 = K_0 v_{\max}$；`rMax` $= K_1$），不是绝对速度。`rStand` 大则站着更抗；`rMax` 大则还在冲时更难失衡。
6. **改 `rChargeScale`**：只改站着蓄力时的抵抗折扣。$\lambda_{\text{charge}}=0$ 等于没蓄；$=1$ 等于已经按这档力度飞出去。
7. **改 `muCtrlScale` / `muSlipScale`**：只改撞后这一段滑多远。自己跳仍用面板上的 $\mu$。

| -------------------------- | ------------------------------------------------------------------------ | ------------- |

## 8. 建议调参顺序

1. **先钉匀速占比**：$k$ 由 $\theta$ 和 $\mu$ 定死，与蓄力无关。
2. **再钉位移表**：`dMin`、`vRate` + `T_max`、$g$。短按多远、满蓄多远、两段各多久由此出。
3. **再钉抵抗两端**：`rStand`、`rMax`。站着挨满蓄应失衡；只慢一点、还在冲，不该单靠体重差就失衡。
4. **最后钉两档 $\mu$**：`muCtrlScale`、`muSlipScale`。只改撞后滑多远。

## 9. 相对 v1 改了什么

v1 用固定时长反推一套更快的表现速度。v2 不再映射，改成真实的两段运动：

|                   | v1                                                                               | v2                                                  |
| ----------------- | -------------------------------------------------------------------------------- | --------------------------------------------------- |
| 水平速度          | 表现速度$2D/T$ 立刻开始掉                                                      | 先不变，落地后才匀减速                              |
| 不变时间 / 总时间 | 没有（或靠 ATK_FADE 硬切）                                                       | $k=2\mu\tan\theta/(2\mu\tan\theta+1)$，与蓄力无关 |
| 跳弧              | 纯表现                                                                           | 抛物线，进位移                                      |
| 碰撞              | 记下的起点$v$             | 换速仍用当前$v$；抵抗 $R$ 用记下的初始速度分档 |                                                     |
