# 斗蛐蛐 · 资源目录管理

当前工程里的图、颜色、CSS 圆都是**临时占位**。正式美术到位后，按本表替换，尽量只换资源、不改玩法代码。

摇杆交互对齐 [prototype-v5](斗蛐蛐原型/prototype-v5/) 的反弹档：`style.css` 的 `#stick` / `#stick-base` / `#stick-knob`，`game.js` 里 `STICK_SIZE=128`、`STICK_VISUAL=38`。原型**没有摇杆贴图**，是 CSS 径向渐变。Unity 占位用同一套色和尺寸；正式图拖进 Theme 即可。

## 1. 资源目录总则

运行时图和 Prefab 按功能收进 `Assets/Resources/`。局内蛐蛐的骨骼、动作、换皮 Prefab **不进** `Resources`。脚本、场景、编辑器工具、TextMesh Pro、插件、Figma 源切、验收截图也不进 `Resources`。

运行时 Prefab 与正式图已按本节收到 `Resources`。必须在 Unity 编辑器里移动，保留 `.meta`，不要在资源管理器剪切。第 2–12 节若仍写旧路径，以本节为准。

### 1.1 局内蛐蛐（不进 Resources）

局内蛐蛐暂时不需要动态加载。骨骼、皮肤、材质和唯一运行时 Prefab 收在 `Art/Characters/`；动作单独放 `Animations/`；战斗逻辑仍在 `Scripts/DouQuqu/`：

```text
Assets/
├─ Art/Characters/
│  ├─ Rig/                           # 共享骨骼、Sprite Library（Unity 里生成）
│  ├─ Skins/
│  │  ├─ LAYER_NAMES.txt             # 22 个图层名，新皮肤必须一字不差
│  │  ├─ defaultCrickets.psb         # 骨骼真源 + 第 0 号皮肤
│  │  ├─ QingTou.psb                 # 之后每套皮肤一个 PSB，平铺在这里
│  │  └─ …
│  ├─ Materials/                     # 描边等材质
│  ├─ Shaders/
│  ├─ Cricket.prefab                 # 1 个可换皮 Prefab，不要 16 份，也不要单独建 Prefabs/
│  ├─ Cricket_Body.png               # 旧占位，PSB Prefab 接上后可删
│  └─ Cricket_Antenna.png
├─ Animations/Characters/Crickets/   # 一份 Animator + 动作，16 套皮肤共用
└─ Scripts/DouQuqu/                  # 蛐蛐战斗逻辑（现有位置，不要新建 Resources/Crickets）
```

原则：**一套骨架、一份动画、十六套皮肤。**

| 放这里                           | 放什么                                                     | 不要放什么                 |
| -------------------------------- | ---------------------------------------------------------- | -------------------------- |
| `Art/.../Rig/`                   | `CricketSkeleton.asset`、`CricketSkins` Sprite Library     | 单套皮肤的 PSB             |
| `Art/.../Skins/`                 | 各皮肤 PSB（图层名与 defaultCrickets 完全一致）            | 骨骼、Animator、Prefab     |
| `Art/Characters/Cricket.prefab`  | 1 个带 Sprite Skin + Sprite Resolver 的 Prefab             | 每种皮肤一份、`Prefabs/` 根目录 |
| `Animations/.../Crickets/`       | `Cricket.controller` 和 Idle / Charge / Jump 等 clip       | 按皮肤复制的动画           |
| `Resources/Crickets/`            | （不要建）                                                 | —                          |

新皮肤 PSB 命名：`Assets/Art/Characters/Skins/<Id>.psb`。`<Id>` 用英文或拼音，例如 `QingTou`、`YouHulu`。16 套齐了再在 Sprite Library 里加 16 个 Label。

**Photoshop 约束（换皮能不能套上骨架，全看这个）：**

- 图层名、数量、前后顺序与 `Skins/LAYER_NAMES.txt` 一致。
- 只改像素，不合并、不重命名、不加新部件。
- 身体比例尽量接近 Default，权重才能共用。
- 骨骼只在 Default 上改。改完后，其它皮肤在 PSD Importer 里勾选同一份 Skeleton Asset。

**Unity 里生成共享骨骼（只做一次）：**

1. 选中 `Skins/defaultCrickets.psb`，Inspector 确认 Character Rig 已开。
2. 在 `Art/Characters/Rig/` 创建 Skeleton Asset，拖回该 PSB 的 Skeleton 槽。
3. 新皮肤 PSB 导入后：Character Rig + 同一个 Skeleton Asset，再在 Skinning Editor 里按共享骨骼生成/拷贝权重。
4. 用 Default 的角色 Prefab 做一份 Sprite Library，每个部件一个 Category，每套皮肤一个 Label。运行时只换 Label，不换 Prefab。

局内优先通过场景直接引用，或在管理器、配置对象的序列化字段中拖入蛐蛐 Prefab；需要生成时使用 `Instantiate(cricketPrefab)`。Prefab 对 2D Animation 贴图、骨骼和动作资源的引用属于编辑器引用，不属于动态加载。

只有在蛐蛐种类或皮肤需要按配置 ID 临时选择、资源需要分包/远程更新，或资源量大到必须按需下载时，才考虑 `Resources` 或 Addressables。当前阶段先不要建立 `Resources/Crickets`。

## 怎么换（通用）

1. 文件放到表里的「放入路径」，覆盖或新建。
2. 在 Unity 里确认导入设置（见各节）。
3. 有 Theme / Prefab 槽的，把新图拖进对应字段。空槽 = 继续用占位。
4. 不要改 `DouQuquRules`、各 System、MatchController。

推荐格式：

| 类型                  | 格式                        | 说明                                           |
| --------------------- | --------------------------- | ---------------------------------------------- |
| 2D 角色 / 道具 / 摇杆 | **PNG，RGBA，正方形** | 透明底。也可用 SVG（项目已装 Vector Graphics） |
| UI 图标               | PNG 或 SVG                  | 透明底                                         |
| 地面 / 罐壁           | PNG 贴图 或 材质            | 地面要能 tile                                  |

PNG 建议 2 的幂（256 / 512 / 1024）。Sprite：`Texture Type = Sprite (2D and UI)`，Mesh Type = Full Rect，Pivot = Center。
