# 斗蛐蛐 · 合成

> 规定战斗之外的育虫盘：放幼虫、同阶段合成、挪格、退出时把精品虫收进背包。读者是策划与程序。
> 以本文为准。[育虫盘原型](../育虫盘/) 仅作行为参考；冲突时以本文为准。
> 范围：入口、棋盘、放幼虫、拖合成 / 挪格、详情、退出收包。不含品质权重、选虫入槽、跳跃公式、美术立绘、对局名次发放。名次发放见 [积分与名次](积分与名次_develop_v0.md)。
> 品质 / 性格 / 名称 / 六维见 [精品虫品质与性格](精品虫品质与性格_develop_v0.md)。选虫页背包见 [对局匹配交互逻辑](对局匹配交互逻辑_develop_v0.md) §2.1。开档卵数与金币上限见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §1。结果页加卵、加金币见 [积分与名次](积分与名次_develop_v0.md)。

⚠️ 育虫盘原型把卵当棋子、中虫合成才定品、成虫同品质再赌升阶，并带虫笼和出售。本文不走这几条：棋子从幼虫放起；成虫合成精品时才抽出；精品虫不能再合成。精品虫可在详情里点「收入背包」，离开育虫盘也会把盘上剩下的精品虫收走。

## 1. 入口

大厅底栏点「育虫盘」进入本页。页标题也是「育虫盘」。

- 村子主页不挂这条底栏；从功能页底栏或返回再进。
- 进战、图鉴、商店与本页平行，切走即退出合成，见 §8。
- 对局内没有合成入口。

页上还有「玩法规则」、中间金圈、右上金币。点「玩法规则」弹出说明窗，形式与主界面「活动介绍」相同：遮罩 + 标题 + 正文 +「知道了」。标题是「玩法规则」。正文写 §4 那条链。点「知道了」或遮罩关闭。

顶栏「背包」打开与选虫页相同的背包界面，默认展开。见 §7。

右上金币只展示当前登录名的金币，本页不改这个数。开档与上限见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §1。

## 2. 棋盘

棋盘 `boardCols` 列 × `boardRows` 行，默认 4 × 5，共 20 格。左上为第 1 格，行优先往右再往下。

| 格上有什么 | 玩家能做 |
| --- | --- |
| 空 | 被挪过来；放幼虫时落到编号最小的空格 |
| 幼虫 / 中虫 / 成虫 | 点开详情；拖到空格挪走；拖到同阶段合成 |
| 精品虫 | 点开详情；拖到空格挪走；不能再合成 |

一格最多一只。棋子没有朝向，格子之间没有相邻限制：任意两格都可以挪或合成。

幼虫 / 中虫 / 成虫留在原格。切走再回来、退出登录再进、重开游戏输入同一名字，盘面仍是离开时的格子。新名字开档为空盘。开局不预放棋子（`initialPieces` 默认 0）。这份盘挂在当前登录名下，见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §3。

---

## 3. 放幼虫

点中间金圈：扣 1 卵，在编号最小的空格放一只幼虫。立刻出现，无孵化等待。

- 落到棋盘，不落到背包，不落到对手。
- 不扣金币。合成、挪格也不改金币。
- 金圈数字 = 当前登录名的虫卵，含 0。开档卵数见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §1。
- 虫卵不够或棋盘已满：金圈无效，盘面与卵数都不变。

---

## 4. 合成链

两只相同阶段拖到一起，目标格升一阶段，原格空出。合成必成功，不掷失败。

```
幼虫 + 幼虫 → 中虫
中虫 + 中虫 → 成虫
成虫 + 成虫 → 精品虫
```

- 幼虫、中虫、成虫没有品质、没有性格。
- 成虫合成精品：当场抽出品质和性格，棋子留在目标格，并写入当前登录名的图鉴。抽出、保底、名称、六维见精品虫分册。
- 同一种精品虫（同一品质 × 同一性格）每合成一次，当前登录名的图鉴次数 +1。
- 精品虫是最高一档，不能再合成。

---

## 5. 挪格与合成

按住一只棋子拖到另一格松手。手指还在原格抬起 = 点一下，开详情，见 §7。

| 拖到 | 结果 |
| --- | --- |
| 空格 | 这只挪过去，原格空 |
| 与自己相同阶段，且未到精品虫 | 按 §4 合成；结果留在目标格，原格空 |
| 不同阶段，或目标已是精品虫 | 无效，这只回到原格 |
| 棋盘外松手 | 无效，这只回到原格 |

拖的过程中原格棋子隐去，手指下跟一个影子。松手后影子消失，按上表结算。

不能一次拖两只。不能把一只拆开。

---

## 6. 盘上怎么显

换态立刻换外形。已经合成完的棋子不改写。

| 态 | 盘上 |
| --- | --- |
| 空格 | 空 |
| 幼虫 / 中虫 / 成虫 | 该阶段外形；不写品质名 |
| 精品虫 | 该品质 × 性格立绘；短名是名字换行性格，见精品虫分册 |
| 拖着 | 原格隐去，手指下是这只的影子 |

合成完成：目标格换成新阶段外形。成虫合成精品时，目标格立刻换成抽出结果，不另开确认窗。

---

## 7. 详情

点盘上有虫的格子弹出详情。点空格不弹。落到被点的那只，不改阶段、不合成。

- 幼虫 / 中虫 / 成虫：只写阶段，说明继续合成可成长为精品虫。六维写 `—`。
- 精品虫：三行是名字、性格、品质，外加六维。见精品虫分册。
- 点关闭收起。遮罩能否关 **待定**。
- 详情里「收入背包」：只对精品虫有效。点下去这只进当前登录名的背包，该格空出，详情关掉。幼虫 / 中虫 / 成虫没有这个按钮。
- 详情里「售卖」：只对精品虫有效。点下去这只从盘上或背包消失，按品质加金币：凡品 20、灵品 40、仙品 80、极品 160。幼虫 / 中虫 / 成虫不能卖。
- 页上「背包」按钮打开与选虫页相同的背包界面，默认展开。点遮罩或「收起」关掉。点卡只看详情，不入槽。
- 离开育虫盘仍会把盘上剩下的精品虫全部收进背包，见 §8。
- 详情打开期间盘面是否仍可拖、是否仍可放幼虫 **待定**。

---

## 8. 退出

离开育虫盘时，盘上所有精品虫自动收进当前登录名的背包，该格空出。幼虫、中虫、成虫留在盘上，不进背包。

算离开的操作：底栏切到进战 / 图鉴 / 商店、点返回回村子主页。切走当时结算，不另点确认。

- 合成当时仍把棋子留在盘上，并写入图鉴。
- 背包只列出已经收进来的精品虫。选虫页不能把虫放回棋盘。
- 一次离开收走盘上全部精品虫，不留一只。

---

## 9. 无效

- 棋盘已满或虫卵不够：点金圈不变。
- 拖到不同阶段、拖到精品虫上、在棋盘外松手：棋子回原格。
- 精品虫不能再合成。拖到空格仍可挪。
- 点空格：不放幼虫、不弹详情。
- 点一下有虫的格：只开详情，不合成。
- 幼虫、中虫、成虫：不进背包。
- 未登录：不能进育虫盘，回登录页。

## 10. 可调配置

> 来源：本篇可调配置（育虫盘 Inspector）

## 11. 验收

- [ ] 底栏「育虫盘」进本页；标题是「育虫盘」。
- [ ] 棋盘 4 × 5，左上第 1 格，行优先。
- [ ] 点金圈，扣 1 卵并在最小编号空格出现一只幼虫；满盘或卵为 0 点金圈不变。
- [ ] 右上金币与大厅一致，本页不改金币。
- [ ] 同一名字重登，未收走的棋子还在原格。
- [ ] 幼虫拖到幼虫得中虫；中虫拖到中虫得成虫；成虫拖到成虫得精品虫。必成功。
- [ ] 成虫合成精品当场抽出品质和性格，棋子留在目标格，当前登录名的图鉴次数 +1。
- [ ] 精品虫不能再合成；拖到空格可挪。
- [ ] 拖到空格 = 挪走；拖到不同阶段或盘外 = 回原格。
- [ ] 点一下开详情：未定品只写阶段；精品虫三行是名字、性格、品质。
- [ ] 离开育虫盘：精品虫进当前名字的背包、该格空；幼虫 / 中虫 / 成虫仍在盘上。
- [ ] 切走再回来，未收走的棋子还在原格。
