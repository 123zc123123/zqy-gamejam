# 斗蛐蛐 · 交互逻辑

> 规定摇杆手势。读者是策划与程序。
> 以本文为准。[prototype-v5](../斗蛐蛐原型/prototype-v5/) 仅作行为参考；冲突时以本文为准。
> 范围：反弹。不含跳跃公式、耐力、拾取、联机。
> 跳跃公式见 [碰撞逻辑与配置](碰撞逻辑与配置_develop_v1.md)：进度 $p=t_{\text{蓄}}/T_{\max}$，水平总位移 $D=d_{\min}(1+p(R-1))$，出手速度由这段距离反推。手势只规定怎么选方向和 $t_{\text{蓄}}$，不换公式。

## 1. 基础规则

- 对局只有一个动作：摇杆选方向、选蓄力时间 $t_{\text{蓄}}$、跳。不能走，没有第二键。
- 必须停稳才能蓄（水平速度为 0，见碰撞 §2.2）。还在飞 / 滑时，输入挂起。
- 耐力不够时只能蓄到负担得起的比例。见碰撞 §4。
- 蓄力中被撞：进度清零，不硬直，不扣耐力。
- 自己跳停稳后可以立刻再蓄。
- 空中不能改方向。
- $t_{\text{蓄min}}$ 可配，含 0。未满 $t_{\text{蓄min}}$ 松手 = 取消、不跳。
- 死区：位移 $< 0.12$ 半径，没有新方向。
- 键盘 WASD / 方向键仅供桌面调试；触屏为输入真源。键盘同样反转。

## 2. 反弹

点按屏幕召出摇杆。往后拉，往前飞。按住计时，松手跳出。

```
点按召出 → 停稳后计时（可边蓄边转）→ 松手跳出
```

- 往后拉，往前飞。摇杆头仍跟手指。
- 虫朝向、蓄力条和虚线画真实飞出方向，不要画成推哪飞哪。
- 按住时间 = $t_{\text{蓄}}$，封顶 $T_{\max}$。蓄满后仍可按着，不再涨，也不自动跳。
- 松手时 $t_{\text{蓄}} < t_{\text{蓄min}}$：取消。
- 被撞后手指还按着：停稳后从 0 再蓄。
- 松手后摇杆消失。

## 3. 蓄力 UI

场上所有人看同一套信号：下蹲 + 身后蓄力条 + 身前虚线与端点圆圈。蓄力中立刻出现；松手跳出、取消、被撞清蓄，三件一起消失。已经飞出的指示不改写。

移动距离 $D$ 见碰撞 §2.1。点跳也出条：$D$ 最短为 $d_{\min}$。

```
蓄力条 $D$ / `chargeBarRatio`     圆      虚线 $D$              端点
████████                         ●     · · · · · · · · ·     ○
圆后方，飞出反方向                      圆前方，飞出方向         落点
```

- **身后蓄力条：** 矩形，贴在碰撞圆后沿，沿飞出反方向向外。长度 $= D$ / `chargeBarRatio`（默认 3）。点跳为 $d_{\min}/3$，蓄满为 $R\,d_{\min}/3$。长度只读这次 $D$，成长和狂暴怎么改 $D$ 见道具。贴图 `strength` 按脚下圆直径等比缩放，用矩形蒙版按该长度揭示，不拉伸。
- **身前虚线：** 从碰撞圆前沿沿飞出方向画到这次 $D$。
- **端点圆圈：** 钉在虚线尽头，即这次落点。
- **颜色：** 蓄力条、虚线、端点圆圈与该玩家描边 / 地面圈同一套玩家色。小蟋蟀跟饲主；无主用中立色。随体型缩小。
- **不透明度：** 蓄力条随这次蓄力进度从 `chargeBarAlphaMin` 到 `chargeBarAlphaMax`。点跳为最小，蓄满为最大。

小蟋蟀也走这一套（见 [道具系统 §6.4](道具系统_develop_v0.md#64-小蟋蟀)）：自动蓄时按这次已蓄对应的 $D$ 画。

> 来源：本篇可调配置

| 旋钮 | 键名 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- | --- |
| 蓄力条长度比 | `chargeBarRatio` | 3 | 1.5–8 | 蓄力条长度 $= D$ / 该值 |
| 蓄力条最小不透明度 | `chargeBarAlphaMin` | 0.4 | 0–1 | 点跳时蓄力条不透明度；简报未给，策划暂定 |
| 蓄力条最大不透明度 | `chargeBarAlphaMax` | 1 | 0–1 | 蓄满时蓄力条不透明度 |

| | 反弹 |
| --- | --- |
| 选方向 | 虫转向，蓄力条和虚线跟上；条在后方、虚线在前方，均与手指方向相反 |
| 选 $t_{\text{蓄}}$ | 下蹲加深；条和虚线随 $D$ 变长 |
| 摇杆 | 点哪出现，头跟手 |

不允许无下蹲的隐形蓄力。

⚠️ 原型仍画一条地面红线。以本文为准。

## 4. 验收

- [ ] 往后拉，条在圆后、虚线在圆前，均朝飞出方向；点跳也出条，长度 $= D$ / `chargeBarRatio`；按住越久 $D$ 越大，条和虚线一起变长；端点圆圈在虚线头；颜色跟玩家色；松手立刻跳；点哪召出摇杆。
- [ ] 键盘同样反转。
- [ ] 被撞后可按住重蓄。
- [ ] 未满 $t_{\text{蓄min}}$ 松手不跳。
- [ ] 不允许无下蹲的隐形蓄力。
