# 斗蛐蛐 · 积分与名次

> 规定本局积分、出局名次、账号积分如何计算，以及它们写在哪些页上。读者是策划与程序。
> 以本文可调配置为准。冲突时以本文为准。
> 范围：本局积分与连杀、出局名次、账号积分、结果页按名次发放、排行。不含出圈判定、三槽换虫、观战手势、登录建档、商店买卵、联机房号。
> 出圈与最后一撞见 [碰撞逻辑与配置](碰撞逻辑与配置_develop_v1.md)。三槽、观战、对局何时结束见 [对局匹配交互逻辑](对局匹配交互逻辑_develop_v0.md)。开档金币 / 虫卵与登录页见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md)。作废见 [联机](联机_develop_v0.md)。成长见 [道具系统](道具系统_develop_v0.md)。

## 1. 本局积分

开局每人 0，连杀也是 0。只在对局里涨，不进大厅顶栏、不进排行、不进结果页发放。

对手的上场虫出圈，且出圈前最后一撞是自己（含自己的小蟋蟀把人撞出去），给自己加分。

加多少 = `killScoreBase` × 加完后的连杀：第 1 次有效击杀 +10，连着第 2 次 +20，第 3 次 +30，依此类推。

分落到该玩家，人机同样加。

有效击杀时连杀先 +1，再按新连杀加分。自己上场虫出圈，连杀归零；换下一槽仍从 0 计。本局积分不清。护盾挡住这次出圈、小蟋蟀自己出圈，连杀与积分都不变。

- 凶手已经出圈或不在场：不加。
- 自己练出圈拉回：不加。
- 停稳后清掉「最后一撞」。之后自己滑出圈，没人拿分。
- 换下一槽、自己出圈，本局积分都保留到对局结束。

> 来源：本篇可调配置

| 旋钮       | 键名              | 默认 | 范围  | 作用                               |
| ---------- | ----------------- | ---- | ----- | ---------------------------------- |
| 击杀分基数 | `killScoreBase` | 10   | 1–99 | 每次有效击杀加「基数 × 当前连杀」 |

## 2. 出局名次

名次是这一局排第几：第 1 最好，第 4 最差。只在 2 人及以上的对局里写。随机匹配、好友组队、训练营都写；自己练、巢穴测试不写。作废整局不算名次，见 [联机](联机_develop_v0.md)。

每人上场三只虫。一只出圈，换下一只，这个人还在场，不排名次。三只都出圈，这个人出局。见 [对局匹配交互逻辑](对局匹配交互逻辑_develop_v0.md)。剩余生命数 = 还没输掉的槽，含场上这只。每人名次只写一次，写过不改。开局不足 4 人，仍按实际人数排，不空出名次。

对局何时结束见对局匹配 §4.1。名次按下面排，从前往后比，能分开就停下：

1. 已经出局的人，按出局先后从后往前排：最先出局的是第 4，接着第 3、第 2；最后出局的是第 1。时间未到、场上只剩 1 人没出局，这个人就是第 1，其余按出局先后排在后面。
2. 时间到了，场上还有人没出局：这些还没出局的人占前面的名次，已经出局的人排在他们后面。还没出局的人之间，剩余生命数多的靠前。
3. 还没出局的人里，剩余生命数相同，本局积分（击杀得分）高的靠前。生命数和本局积分也相同：**待定**。
4. 名次排好后，按名次给账号积分。发多少见 §4。
5. 结果页写出：名次、玩家、排名得分、击杀得分。排名得分是这次按名次加上的账号积分；击杀得分是本局积分。训练营同样写这四项，排名得分不加进账号。

## 3. 账号积分

账号积分挂在当前登录名下，人机不建档。新名字开档为 `startScore`（默认 0），加完不超过 `scoreCap`。

只给本机当前登录名加。局域网打完只改本机这一份，不改别人设备上的档。

有名次（第 1–4）才按 §4 加。本机出现本局结果时发一次；同一局同一登录名只加一次。已经加过的这一局再看结果页，不加第二遍。

- 自己出圈后选「继续看」：等到对局结束出结果再发。
- 自己出圈后选「退出本局」：本机出结果时按当时名次发。
- 作废不加。
- 训练营、自己练、巢穴测试不加。
- 合成、挪格、商店非虫卵价签、日勤「领取」、排行点行：不改账号积分。

> 来源：本篇可调配置。标「策划暂定」的数简报未给。

| 旋钮     | 键名           | 默认   | 范围            | 作用       |
| -------- | -------------- | ------ | --------------- | ---------- |
| 开档积分 | `startScore` | 0      | 0–`scoreCap` | 策划暂定   |
| 积分上限 | `scoreCap`   | 999999 | 0–999999       | 加到此为止 |

## 4. 结果页发放

仅随机匹配与好友组队按名次发放。读 §2 写出的名次，把下表排名得分加进账号，同时加金币、虫卵。金币、虫卵上限见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md)。击杀得分是本局积分，只写在结果页上，不加进账号。场上不足 4 人时，仍按实际名次读这一行。训练营结果页同样写出名次、玩家、排名得分、击杀得分，排名得分不加进账号。

> 来源：本篇可调配置。简报未给具体数，下表为策划暂定。排名得分、金币范围 0–999；虫卵 0–`eggCap`。

| 名次 | 排名得分            | 金币              | 虫卵            |
| ---- | ------------------- | ----------------- | --------------- |
| 第 1 | `pointsPlace1` 50 | `goldPlace1` 40 | `eggPlace1` 8 |
| 第 2 | `pointsPlace2` 30 | `goldPlace2` 24 | `eggPlace2` 6 |
| 第 3 | `pointsPlace3` 10 | `goldPlace3` 14 | `eggPlace3` 4 |
| 第 4 | `pointsPlace4` 5  | `goldPlace4` 8  | `eggPlace4` 2 |

## 5. 怎么显

数字怎么算见 §1–§4。换态立刻换成新值，已经写出的旧数字不回放。

| 位置              | 写什么                                                                                                                                 |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 对局玩家卡        | 按座位排，不按分数、不按名次重排。名字旁写本局积分；头像右上连杀 ≥ 1 才写出数字，归零立刻收掉。人已出局：卡仍在，本局积分保留，卡变淡 |
| 进战 / 选虫玩家卡 | 当前登录名；旁边是账号积分                                                                                                             |
| 大厅顶栏          | 当前名字、账号积分、金币。§4 加完后回到大厅立刻写成新值                                                                               |
| 结果页            | 见 §2                                                                                                                                 |
| 排行              | 见 §6                                                                                                                                 |

> Prefab：对局 HUD `Battle/Hud/Prefabs/Battle`；结算 `Settlement/Prefabs/Jiesuan`；排行 `Ranking`；进战 / 选虫玩家卡。

## 6. 排行

大厅底栏点「排行」进本页。未登录不能进，回登录页。对局内没有排行入口。

列出这台设备上所有登过的名字，按账号积分从高到低。积分相同：先登录成功的排在前面。只读账号积分，不读本局积分、金币、虫卵、蟋蟀。点某一行：不进别人的档，不改自己的数。

| 态             | 页上                                      |
| -------------- | ----------------------------------------- |
| 有人登过       | 名字 + 账号积分，高分在上；当前登录名可辨 |
| 只有当前这一名 | 一行，就是自己                            |

已经写上的行不因旁人打完一局而改写，除非回到本页再列一次。

## 7. 无效

- 撞了没出圈；吃饲料球、吃限时道具、砸房子；自己撞自己；友方小蟋蟀互撞。
- 图鉴进页、底栏切页：不改账号积分。
- 商店非虫卵价签、日勤「领取」、排行点行：不改账号积分、金币、虫卵。
- 作废、训练营、自己练、巢穴测试：不发账号积分、金币、虫卵。
- 同一局已加过：结果页再看不加第二遍。

## 8. 验收

- [ ] 开局四人本局积分、连杀都是 0。
- [ ] 把对手上场虫撞出圈：自己 +10；连杀不断再撞出一只：再 +20。
- [ ] 自己出圈：连杀收掉，本局积分仍在；换下一槽连杀仍从 0。
- [ ] 护盾挡住出圈：双方本局积分和连杀都不变。
- [ ] 小蟋蟀自己出圈：没人加本局积分。小蟋蟀把对手撞出圈：分记饲主。
- [ ] 停稳后再自己滑出圈：没人加本局积分。
- [ ] 对局玩家卡按座位排，名字旁是本局积分，头像右上是连杀；出局后卡变淡、分仍在。
- [ ] 进战 / 选虫玩家卡写账号积分，不写本局积分。
- [ ] 四人局：最先出局第 4，接着第 3、第 2，最后留下或最后出局的第 1。一只虫出圈只换槽，不排名次。
- [ ] 时间到了还剩多人：剩余生命数多的靠前；生命数相同，本局积分高的靠前。已经出局的人排在他们后面。
- [ ] 结果页写出名次、玩家、排名得分、击杀得分。
- [ ] 作废：所有人名次都不算。
- [ ] 新名开档账号积分 0；大厅顶栏写出账号积分。
- [ ] 随机匹配 / 好友组队：排名得分加进账号，同时加金币、虫卵，只加一次；作废、训练营、自己练、巢穴测试不加。
- [ ] 训练营结果页同样写出四项，排名得分不加进账号。自己练不写名次、不加本局积分。
- [ ] 排行按本机各名字的账号积分从高到低；当前登录名可辨。
- [ ] 本局积分不加进大厅顶栏。
