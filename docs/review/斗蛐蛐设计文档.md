## 随包默认

公式见碰撞分册。打开即可玩到的默认数值在 `defaults.js`：

- 运动：$A_1=80$，$T_{\max}=0.4\,\mathrm{s}$，$\theta=15°$，$g=80$，$\mu=1.8$，$d_{\min}=8$，`bugR=1.8`
- 耐力：上限 5，满蓄扣 1，消耗与蓄力比例成正比，落地恢复 0.6 / s，5 格
- 交互：反弹
- 道具：到点一次补 `itemBatch=3` 颗，不超过 `itemCap=3`

碰撞分册 §2 演算举例便于手算，不是随包默认。

待定：随包 `rStand = rMax = 0.4`，与碰撞分册「必须 $K_0 < K_1$」不一致。是否关闭速度抬升，本文不改规则。
