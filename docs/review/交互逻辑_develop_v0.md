## 1. 基础规则

- 对局只有一个动作：摇杆选方向、选蓄力时间 $t_{\text{蓄}}$、跳。不能走，没有第二键。
- 必须停稳才能蓄（落地且水平速度 $< 0.06$）。还在飞 / 滑时，输入挂起。
- 耐力不够时只能蓄到负担得起的比例。见碰撞 §4。
- 蓄力中被撞：进度清零，不硬直，不扣耐力。
- 自己跳落地可以立刻再蓄。
- 空中不能改方向。
- $t_{\text{蓄min}}$ 可配，含 0。未满 $t_{\text{蓄min}}$ 松手 = 取消、不跳。
- 死区：位移 $< 0.12$ 半径，没有新方向。
- 键盘 WASD / 方向键仅供桌面调试；触屏为输入真源。键盘同样反转。

## 2. 反弹

点按屏幕召出摇杆。往后拉，往前飞。按住计时，松手跳出。

```
点按召出 → 停稳后计时（可边蓄边转）→ 松手跳出
```

- 往后拉，往前飞。摇杆头仍跟手指。
- 虫朝向和红线画真实飞出方向，不要画成推哪飞哪。
- 按住时间 = $t_{\text{蓄}}$，封顶 $T_{\max}$。蓄满后仍可按着，不再涨，也不自动跳。
- 松手时 $t_{\text{蓄}} < t_{\text{蓄min}}$：取消。
- 被撞后手指还按着：停稳后从 0 再蓄。
- 松手后摇杆消失。

## 3. 蓄力 UI

场上所有人看同一套信号：下蹲 + 地面红线。红线方向 = 将要飞出的方向，长度 = 这次 $T_{\text{跳}}$ 对应的跳距，最短为点跳 $d_{\min}$。小蟋蟀也走这一套（见 [道具系统 §6.4](道具系统_develop_v0.md#64-小蟋蟀)）：自动蓄时红线从 0 长到 `babyChargeT` 对应跳距。

| | 反弹 |
| --- | --- |
| 选方向 | 虫转向，红线跟上；红线与手指方向相反 |
| 选 $t_{\text{蓄}}$ | 下蹲和红线随按住时间变长 |
| 摇杆 | 点哪出现，头跟手 |

不允许无下蹲的隐形蓄力。

---

## 4. 验收

- [ ] 往后拉，红线朝反方向；按住越久越远；松手立刻跳；点哪召出摇杆。
- [ ] 键盘同样反转。
- [ ] 被撞后可按住重蓄。
- [ ] 未满 $t_{\text{蓄min}}$ 松手不跳。
- [ ] 不允许无下蹲的隐形蓄力。
