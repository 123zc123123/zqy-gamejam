## 1. 基础规则

- 对局只有一个动作：摇杆选方向、选加速时间 $t$、跳。不能走，没有第二键。
- 必须停稳才能蓄（落地且水平速度 $< 0.06$）。还在飞 / 滑时，输入挂起。
- 耐力为 0 不能蓄力；耐力不足满蓄时只能蓄到负担得起的比例。见碰撞 §4。
- 蓄力中被撞：进度清零，不硬直，不扣耐力。
- 自己跳落地可以立刻再蓄。
- 空中不能改方向。
- $T_{\min}$ 可配，含 0。未满 $T_{\min}$ 松手 = 取消、不跳。
- 死区：位移 $< 0.12$ 半径，没有新方向。
- 旋钮「交互」三选一。切档清除当前蓄力，不跳，不补满耐力。人机不读该旋钮。
- 键盘 WASD / 方向键仅供桌面调试；触屏为输入真源。

## 2. 三种移动交互逻辑

| | 现版 | 反弹 | 滑长 |
| --- | --- | --- | --- |
| 圆盘 | 点哪召出 | 同现版 | 钉在屏幕下方，圆心常驻 |
| 方向 | 推向要去的地方 | 往后拉，反方向飞 | 圆心指向指头 |
| $t$ 从哪来 | 按住多久 | 同现版 | 拉出多长 |
| 何时跳 | 松手就跳 | 同现版 | 松手后把这段 $t$ 跑完，再自动跳 |

### 2.1 现版

点按屏幕召出摇杆。推向要跳的方向，按住计时，松手跳出。

```
点按召出 → 停稳后计时（可边蓄边转）→ 松手跳出
```

- 按住时间 = $t$，封顶 $T_{\max}$。蓄满后仍可按着，不再涨，也不自动跳。
- 松手时 $t < T_{\min}$：取消。
- 被撞后手指还按着：停稳后从 0 再蓄。
- 松手后摇杆消失。

### 2.2 反弹

和现版同一套：召出、按住计时、松手跳。只把发射方向取反。

- 往后拉，往前飞。摇杆头仍跟手指。
- 虫朝向和红线画真实飞出方向，不要画成推哪飞哪。
- 键盘同样反转。

### 2.3 滑长

圆盘钉死在屏幕下缘，比现版召出盘大（约 220 px），圆心一直看得见。不跟手走。

**拉杆（没松手）**

- 必须按在圆盘上（含一点外沿）。点场地别处不出招。
- 从圆心往外拉。方向 = 圆心 → 指头。长度 $\mathrm{mag}$ = 到圆心的距离 / 半径，超过半径按 1。
- 这一段不按墙钟涨 $t$。按住不动，预览就不变。

**松手**

- $\mathrm{mag} < 0.12$，或换算的 $t < T_{\min}$：取消。
- 否则锁方向，锁 $t = \mathrm{mag}\cdot T_{\max}$。没停稳就挂起，停稳后开始跑表。
- 提交后不能再改方向、不能再改 $t$。

**跑表（松手之后）**

- 虫正式下蹲。$\mathrm{chargeT}$ 从 0 加到锁死的 $t$。
- 到点自动跳出。
- 跑表中被撞：打断，不跳，要重新拉。没有第二键取消。

键盘没有滑长：按一下给方向，松手视为拉满，跑完 $T_{\max}$ 再跳。不要用按住时间去模拟这一档。

## 3. 蓄力 UI

场上所有人看同一套信号：下蹲 + 地面红线。红线方向 = 将要飞出的方向，长度 = 这次 $t$ 对应的跳距。小蟋蟀也走这一套（见 [道具系统 §6.4](道具系统_develop_v0.md#64-小蟋蟀)）：自动蓄时红线从 0 长到 `babyChargeT` 对应跳距，不读交互三档。

| | 现版 / 反弹 | 滑长 |
| --- | --- | --- |
| 选方向 | 虫转向，红线跟上 | 同左；拉杆时红线是预览，更淡 |
| 选 $t$ | 下蹲和红线随按住时间变长 | 拉杆时只有轻预览；松手后下蹲和红线按 $t$ 从 0 长出来 |
| 摇杆 | 点哪出现，头跟手 | 大圆盘 + 圆心钉死；头表示当前拉动；提交后回中 |
| 反弹特有 | 红线与手指方向相反 | — |

不允许无下蹲的隐形蓄力。滑长若做成「松手立刻跳」，这套 UI 就失去意义。

## 4. 验收

- [ ] 随包默认反弹；切到现版 / 滑长后，满蓄跳距仍同一档。
- [ ] 现版：推哪飞哪；按住越久越远；松手立刻跳；点哪召出摇杆。
- [ ] 反弹：往后拉，红线朝反方向；时间规则与现版相同。
- [ ] 滑长：圆盘钉死、有圆心、明显更大；必须从盘上拉。
- [ ] 滑长：短拉先蹲再小跳；拉满蹲得更久、跳得更远；按住不动预览不涨。
- [ ] 滑长：圆盘外点按、死区松手，都不跳。
- [ ] 切档时，正在蓄力的那一下不会飞出。
- [ ] 被撞后：现版 / 反弹可按住重蓄；滑长要重新拉。
- [ ] 同一组 $A_1 / T_{\max} / \theta$，三档满蓄跳距同一档。
