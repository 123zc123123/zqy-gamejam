# 斗蛐蛐 · 对局模式

> 规定开场入口、准备、胜负、观战、人机与巢穴测试。读者是策划与程序。
> 以本文与 `defaults.js` 为准。[prototype-v5](../斗蛐蛐原型/prototype-v5/) 仅作行为参考；冲突时以本文为准。
> 范围：如何进入对局、何时可蓄力、如何结束、出圈后如何观战。不含跳跃公式、手势、拾取投放、巢穴链。
> 时长与狂暴见 [道具系统](道具系统_develop_v0.md)。手势见 [交互逻辑](交互逻辑_develop_v0.md)。耐力见 [碰撞逻辑与配置-v4](碰撞逻辑与配置_develop_v0.2.md) §4。开房细则见 [联机](联机_develop_v0.md)。

## 1. 开场入口

开场提供四个入口。对局内无第二键。

| 入口 | 人数 | 对手 | 准备 3 秒 | 计时 / 胜负 |
| --- | --- | --- | --- | --- |
| 开罐 | 2 | 人机「贪蓄」 | 有 | 正赛 + 加时；出圈即负 |
| 自己练 | 1 | 无 | 无 | 不计胜负；出圈拉回 |
| 开房对打 | 2 | 另一名玩家 | 有 | 同开罐；主机跑物理 |
| 加入 | 2 | 房主 | 有 | 同开罐；客机发摇杆 |

- 点「开罐」或「自己练」会断开当前联机。
- 「开房对打 / 加入」见 [联机](联机_develop_v0.md)。未启动保存服务则无法开房。
- 旋钮开场可调，局内打开则暂停。

开罐 / 联机站位：纵轴 ±38% 半深，面向场心。名称：青头 / 油葫芦。本地座位为己方。

开场显示四键；入局后 HUD 显示对战中或联机对战。不弹说明窗。

## 2. 准备倒计时

开罐与联机进入 3 秒准备：双方不能蓄力、不能跳。倒计时结束起算正赛 0:00，并开始投放计时。

| 状态 | 能否蓄力 | 计时 |
| --- | --- | --- |
| 准备 | 否 | 不计入正赛 |
| 正赛 / 加时 | 停稳且耐力 ≥ 起跳耐力 | 计入 |
| 暂停 / 打开旋钮 | 否 | 不计入 |
| 出圈询问「继续看 / 退出」 | 否（对局暂停） | 不计入 |
| 观战中 | 自己不能操作 | 计入（对局继续） |

自己练、巢穴测试跳过准备，进场即可蓄力。

## 3. 胜负

仅开罐与联机结算。自己练、巢穴测试不结束对局。

1. 存活玩家只剩 1 人：该人胜。击杀记最后一撞；小蟋蟀记饲主。
2. 几乎同时出圈、场上无人：双方出局，本局无胜者。
3. 硬截止仍有 2 人：比地面投影到场心的距离，近者胜；距离相同比本局成长层；再同则平。
4. 联机中途对手离开或断线：本局作废。

出圈判定、护盾拉回见 [碰撞逻辑与配置-v4](碰撞逻辑与配置_develop_v0.2.md) 与 [道具系统](道具系统_develop_v0.md) §5.4。正赛 / 加时 / 硬截止时长见道具系统 §2。

HUD：正赛显示距加时；狂暴显示距硬截止；场地变色。不弹说明窗。

## 4. 观战

自己出圈且场上仍有人时，对局暂停，出示「继续看 / 退出本局」。

| 选择 | 之后 |
| --- | --- |
| 继续看 | 解除暂停，对局打到结束；自己不能再蓄力 |
| 退出本局 | 本局对自己结束；对手若仍在场则继续 |

观战仍以本地座位为己方，描边与地面圈不变色。敌方主蟋蟀地面圈用虚线，小蟋蟀用实线。

出圈询问盖住摇杆。阵营色见文末美术交接，本文不定色值。

## 5. 开罐人机

开罐对手固定为「贪蓄」。共用停稳、耐力、跳跃公式。人机自己选方向并按住计时，不读玩家摇杆反转。

决策顺序：

1. 贴边且仍向外滑 → 短跳拉回。
2. 否则有概率抢近处限时道具（狂暴中只看护盾）或饲料球。
3. 否则瞄准对手偏出圈方向。
4. 不预判小蟋蟀，不绕障。

> 来源：代码常量（不进面板）

| 旋钮 | 键名 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- | --- |
| 蓄力倍率 | `chargeMul` | 1.2 | — | 对人蓄力时长的倍率 |
| 思考间隔 | `react` | 0.28 s | — | 松手后至下一次决策 |
| 预判位移 | `lead` | 0.22 | — | 瞄准对手时的位移提前量 |

联机不含人机。巢穴测试对手为木桩，见 §7。

## 6. 自己练

场上仅自己。无倒计时、不计胜负、无人机。

自己出圈：拉回开局位 `(0, -0.38×半深)`，速度清零，护盾与成长保留。对局不结束。

房子仍按道具系统投放。场上无敌人时，小蟋蟀做无定向短跳。

## 7. 巢穴测试

入口为同地址下的巢穴测试页，不在开场四键中。

- 开场场心已有一栋房子。
- 两只都在场；未控制的那只为木桩，不跳。
- Tab 切换当前控制的蟋蟀。切走的立刻变为木桩，清除当前蓄力，不跳。
- 无倒计时，不按开罐结算胜负。

## 8. 暂停与重开

- 空格暂停 / 继续。局内打开旋钮即暂停。
- R 重开：非联机立即再来一局；联机客机不能重开，须等房主再开。
- 重开对局才回满耐力，并清除成长、场上拾取物与巢穴。
