## 1. 开场入口

未登录不能进本页，回登录页。见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §1。

大厅进战页提供两个平行入口。对局内无第二键。己方位写当前登录名。

| 入口 | 人数 | 对手 | 准备 3 秒 | 计时 / 胜负 |
| --- | --- | --- | --- | --- |
| 随机匹配 | 4 | 匹配到的玩家 | 有 | 正赛 + 加时；出圈即负 |
| 好友组队 | 4 | 同一房号的玩家 | 有 | 同随机匹配 |

- 入口名是「随机匹配」和「好友组队」。⚠️ 不用「开罐」「开始匹配」。
- 好友组队：房号在右，右侧是「确认」。点「确认」进房。房号是否校验 **待定**：现版点确认即进房。
- 点「随机匹配」：进入等待房，并进入选虫页，在选虫页选己方三只虫。
- 好友组队点「确认」：进入等待房，不进选虫页。原两个入口的位置出现「准备」。点「准备」才进选虫页。
- 旋钮开场可调，局内打开则暂停。

自己练、巢穴测试不在这两个入口里，见 §5。Unity 大厅是否仍提供自己练 **待定**。

```
进战页
  ├─ 随机匹配 → 等待房 + 选虫页
  └─ 好友组队「确认」→ 等待房 →「准备」→ 选虫页
选虫页「准备就绪」或倒计时到 0 → 己方锁定，停在本页
进场 3 秒准备 → 正赛
```

何时进场见联机。游戏里现在的做法：锁定后不进场。

### 1.1 未进房 / 等待房

| 状态 | 随机匹配 / 好友组队 | 四人位 + 离开房间 | 「准备」 | 底栏 |
| --- | --- | --- | --- | --- |
| 未进房 | 显示 | 不显示 | 不显示 | 显示，可切页 |
| 随机匹配后 | 隐藏 | 一起出现 | 不显示 | 隐藏，已进选虫页 |
| 好友组队等待 | 隐藏 | 一起出现 | 显示在四人位下方 | 隐藏，不能切页 |

- 「离开房间」：退出等待房，回到未进房，「准备」一并隐藏。
- 等待房仍可点进度条看日勤，仍可点「玩法规则」。
- 好友组队的「准备」点下去才进选虫页。

四人站位 **待定**。本地座位为己方。选虫页只写己方这一行；对手行怎么显、对手何时准备，不在本文。

「返回」离开选虫页，回到进战页。本次三槽不保留；下一次进页三个槽都是空的。

### 1.2 玩法规则

点「玩法规则」弹出说明窗。形式与主界面「活动介绍」相同：遮罩 + 标题 + 正文 +「知道了」。

标题是「玩法规则」，不是「活动介绍」。点「知道了」或遮罩关闭。

### 1.3 日勤

点进度条（蛐蛐新手条 / 宝箱）在当前页弹出日勤，不切页。点「返回」或遮罩关闭。

「领取」只切按钮态：可领 → 已领取。不改进度数字，不改积分、金币、虫卵。任务档位与数值 **待定**。

## 2. 选虫

选虫页为己方选上场三只精品虫。背包从育虫盘来；三槽决定开局顺序和出圈换虫；绿框标当前槽；点卡入槽；「准备就绪」或倒计时到 0 锁定。页上怎么显见 §2.5。

### 2.1 背包从哪来

每次退出合成（离开育虫盘）时，盘上所有 4 级虫（精品虫）自动收进当前登录名的背包，该格空出。幼虫、中虫、成虫留在盘上，不进背包。

- 合成当时仍把棋子留在盘上，并写入当前登录名的图鉴，见精品虫分册。
- 背包只列出当前登录名已经收进来的精品虫。换名字看到的是另一份。
- 选虫页不能把虫放回棋盘。

### 2.2 己方三槽

每人上场三只蟋蟀，从左到右为第 1、第 2、第 3 槽。开局用第 1 槽。当前这只出圈后换下一槽，从该玩家开局位再进场。三只都出圈，该玩家出局。

- 槽里只能是精品虫。
- 槽上写品质、名称、立绘。名称按精品虫分册，已区分性格；性格四字不另写一行。手感在开局时按该分册叠到碰撞量上。
- 同一只虫不能同时占两个槽。
- 空槽不算一只上场虫。人手动点「准备就绪」必须三槽都有虫。倒计时到 0 的补槽见 §2.4。

> 来源：本篇可调配置

| 旋钮 | 键名 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- | --- |
| 每人上场只数 | `livesPerPlayer` | 3 | 1–3 | 己方槽位数；出圈后按槽序换下一只 |

### 2.3 绿框、展开背包、点虫入槽

己方三槽上有一个绿色的方框，标当前槽。点一个位置，绿框移到那一槽。再点背包，就是为当前槽选蟋蟀。

- 进页时绿框在第 1 槽。
- 点某一个槽：绿框移过去。不弹详情、不改槽里已有的虫。
- 未准备时点「展开背包」或背包顶栏：己方这一行、背包、「准备就绪」整体上移，盖住另外三名玩家（隐藏）。按钮变成「收起」。
- 点「收起」：己方行、背包、「准备就绪」移回，另外三人重新显示。按钮变回「展开背包」。三槽、绿框、已选的虫都不变。
- 背包不是另开一层再关掉。展开时仍可点己方槽换绿框。
- 收起时点栏目无效。
- 已准备时绿框收掉；点「展开背包」无效，见 §7。

背包只列出精品虫。顶栏五个栏目一次只亮一个：

| 栏目 | 列出 |
| --- | --- |
| 全部 | 背包里所有精品虫 |
| 强攻 | 性格为强攻 |
| 灵巧 | 性格为灵巧 |
| 智谋 | 性格为智谋 |
| 沉稳 | 性格为沉稳 |

展开时栏目为「全部」。点另一个栏目立刻换列表，不改已经入槽的虫。该栏目下一只都没有：列表空，不报错。

⚠️ 切图栏目写「机灵 / 勇猛 / 沉着 / 威严」，品级写「良品 / 优品」，槽上还有「四品」。正文用精品虫分册：性格「强攻 / 灵巧 / 智谋 / 沉稳」，品质「凡品 / 灵品 / 仙品 / 极品」。切图按正文改。

背包展开时，点一张卡：这只虫进入当前绿框槽，立刻写上品质、名称、立绘。不弹详情。落到己方当前绿框槽，不落到对手。绿框不自动跳到下一空槽。

- 入槽后这只虫在背包里标成已选，不能再点进别的槽。把槽里的虫换掉之后，被换下来的那只重新可选。
- 点已入槽的那张卡：不变，也不会从原槽挪到当前绿框。

### 2.4 准备就绪

三槽都有虫时，点「准备就绪」：己方锁定三槽，不能再改槽、不能再展开背包。若背包是展开的，先收起。显隐见 §2.5。

未满三槽点「准备就绪」：无效，三槽不变。

已准备后不能取消。要改槽只能「返回」离开本页。

锁定后停在本页，不进场。何时进场见联机。游戏里现在的做法：锁定后不进场。

页上有倒计时，从进选虫页起算。已准备后仍减到 0。

> 来源：本篇可调配置

| 旋钮 | 键名 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- | --- |
| 选虫时限 | `selectSeconds` | 59 | 10–120 | 进页后的倒计时秒数 |

到 0 时若己方还没准备：

1. 已经选好的槽不动。
2. 空槽从背包里尚未入槽的精品虫里随机填入。
3. 不够填的空槽保持空，该玩家少一条命。
4. 若背包是展开的，先收起。
5. 己方视为已准备，三槽锁定。显隐见 §2.5。

到 0 时若已经准备：不再随机。

开局后这三只按 §2.2 的槽序上场。选虫页选虫到此结束。

### 2.5 选虫页怎么显

页标题是「四人混战」。底栏隐藏。入槽、锁定、倒计时补槽见上文。

| 状态 | 己方三槽 | 另外三人 | 背包 | 按钮 |
| --- | --- | --- | --- | --- |
| 刚进页 | 空槽；绿框在第 1 槽 | 显示 | 收着，跟在己方行下 | 「展开背包」 |
| 选虫中、收起 | 有虫的槽写品质和名称；绿框在当前槽 | 显示 | 收着 | 「展开背包」 |
| 选虫中、展开 | 己方行、背包、「准备就绪」上移；绿框仍可点 | 隐藏 | 列出精品虫；当前栏目高亮；已选的卡可辨 | 「收起」 |
| 已准备 | 三槽锁定；绿框收掉 | 显示 | 不能展开 | 行上「已准备」；页底「准备就绪」仍在但不能点 |

倒计时从进页起一直减，见 §2.4。换栏目、入槽、展开 / 收起、准备，都立刻换表现。已经入槽的虫不因为换栏目或收起而消失。

## 3. 开局准备

随机匹配与好友组队进入 3 秒准备：四人都不能蓄力、不能跳。倒计时结束起算正赛 0:00，并开始投放计时。

| 状态 | 能否蓄力 | 计时 |
| --- | --- | --- |
| 准备 | 否 | 不计入正赛 |
| 正赛 / 加时 | 停稳 | 计入 |
| 暂停 / 打开旋钮 | 否 | 不计入 |
| 出圈询问「继续看 / 退出」 | 否（对局暂停） | 不计入 |
| 观战中 | 自己不能操作 | 计入（对局继续） |

自己练、巢穴测试跳过准备，进场即可蓄力。

## 4. 胜负、观战与结果发放

仅随机匹配与好友组队结算。自己练、巢穴测试不结束对局。

### 4.1 胜负

1. 存活玩家只剩 1 人：该人胜。击杀记最后一撞；小蟋蟀记饲主。
2. 几乎同时出圈、场上无人：本局无胜者。
3. 硬截止仍有 2 人及以上：比地面投影到场心的距离，近者胜；距离相同比本局成长层；再同则平。
4. 中途有人离开或断线：本局作废。

出圈判定、护盾拉回见 [碰撞逻辑与配置](碰撞逻辑与配置_develop_v1.md) 与 [道具系统](道具系统_develop_v0.md) §5.4。正赛 / 加时 / 硬截止时长见道具系统 §2。

HUD：正赛显示距加时；狂暴显示距硬截止；场地变色。不弹说明窗。

### 4.2 观战

自己出圈且场上仍有人时，对局暂停，出示「继续看 / 退出本局」。

| 选择 | 之后 |
| --- | --- |
| 继续看 | 解除暂停，对局打到结束；自己不能再蓄力；对局结束出结果时按 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §5 发放 |
| 退出本局 | 本局对自己结束；对手若仍在场则继续；本机出结果时按当时名次走 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §5 |

观战仍以本地座位为己方，描边与地面圈不变色。敌方主蟋蟀地面圈用虚线，小蟋蟀用实线。

出圈询问盖住摇杆。阵营色见文末美术交接，本文不定色值。

### 4.3 结果页发放

本机出现结果时，按名次给当前登录名加积分、金币、虫卵。发多少、同一局只加一次，见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §5。

## 5. 人机、自己练、巢穴测试

空位是否补人机、自己练、巢穴测试都不走大厅两个入口的完整流程。人机只在随机匹配 / 好友组队里补对手；自己练和巢穴测试跳过选虫锁定进场、开局 3 秒和胜负结算。

### 5.1 人机

空位是否补人机 **待定**。补人机时对手用「贪蓄」。共用停稳、耐力、跳跃公式。人机自己选方向并按住计时，不读玩家摇杆反转。

决策顺序：

1. 贴边且仍向外滑 → 短跳拉回。
2. 否则有概率抢近处限时道具（狂暴中只看护盾）或饲料球。
3. 否则瞄准对手偏出圈方向。
4. 不预判小蟋蟀，不绕障。

> 来源：代码常量（不进面板）

| 旋钮 | 键名 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- | --- |
| 蓄力倍率 | `chargeMul` | 1.2 | — | 对人蓄力时长的倍率 |
| 思考间隔 | `react` | 0.28 s | — | 松手后至下一次决策 |
| 预判位移 | `lead` | 0.22 | — | 瞄准对手时的位移提前量 |

巢穴测试对手为木桩，见 §5.3。

### 5.2 自己练

场上仅自己。无倒计时、不计胜负、无人机。不在大厅两个入口里。

自己出圈：拉回开局位 `(0, -0.38×半深)`，速度清零，护盾与成长保留。对局不结束。

房子仍按道具系统投放。场上无敌人时，小蟋蟀做无定向短跳。

### 5.3 巢穴测试

入口为同地址下的巢穴测试页，不在大厅两个入口里。

- 开场场心已有一栋房子。
- 两只都在场；未控制的那只为木桩，不跳。
- Tab 切换当前控制的蟋蟀。切走的立刻变为木桩，清除当前蓄力，不跳。
- 无倒计时，不按随机匹配 / 好友组队结算胜负。

## 6. 暂停与重开

- 空格暂停 / 继续。局内打开旋钮即暂停。
- R 重开：非联机立即再来一局；联机客机不能重开，须等房主再开。
- 重开对局才回满耐力，并清除成长、场上拾取物与巢穴。

---

## 7. 无效

- 未登录：不能进本页，回登录页。
- 幼虫、中虫、成虫：不进背包，不能入槽。
- 已选进某一槽的虫：不能再进别的槽；点那张卡不变。
- 已准备：点槽、点卡、点「展开背包」、点「准备就绪」都不变。
- 未满三槽：点「准备就绪」不变。倒计时到 0 除外，见 §2.4。
- 收起时点栏目：不变。
- 背包当前栏目为空：点空白处无入槽。
- 对手行：点上去不改己方三槽。

## 8. 验收

- [ ] 离开育虫盘时，盘上精品虫进背包、该格空出；幼虫 / 中虫 / 成虫仍在盘上。
- [ ] 随机匹配进选虫页；好友组队先等待房，点「准备」才进选虫页。
- [ ] 选虫页见到己方三槽、绿框、「展开背包」。
- [ ] 点一个槽，绿框移过去；点「展开背包」，己方行连着背包和「准备就绪」上移，另外三人隐藏，按钮变成「收起」。
- [ ] 点「收起」移回，另外三人重新显示；三槽不变。
- [ ] 点一张卡立刻进入当前绿框槽，不弹详情。
- [ ] 「返回」后再进选虫页，三槽为空。
- [ ] 同一只虫不能占两槽；被换下后可再选；点已入槽的卡不变。
- [ ] 三槽未满时「准备就绪」无效；满三槽后锁定，行上「已准备」，绿框收掉，不能再改；页底「准备就绪」仍在但不能点。
- [ ] 倒计时到 0：已选的保留，空槽从剩余精品虫里随机补，然后锁定。
- [ ] 锁定后停在本页，不进场。
- [ ] 开局第 1 槽先上场，出圈换第 2 槽，再换第 3 槽。
- [ ] 进场 3 秒内不能蓄力、不能跳；结束起算正赛。
