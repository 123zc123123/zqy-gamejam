## 1. 开场入口

未登录不能进本页，回登录页。见 [登录逻辑与配置](登录逻辑与配置_develop_v0.md) §1。

大厅进战页提供三个入口。对局内无第二键。己方位写当前登录名。

| 入口 | 人数 | 对手 | 准备 3 秒 | 计时 / 胜负 |
| --- | --- | --- | --- | --- |
| 随机匹配 | 4 | 匹配到的玩家 | 有 | 单局 2 分钟；出圈即负 |
| 好友组队 | 4 | 同一房号的玩家 | 有 | 同随机匹配 |
| 训练营 | 4 | 三人机 | 有 | 同随机匹配：单局 2 分钟、1:30 狂暴并收口；结果页不发放 |

- 入口名是「随机匹配」「好友组队」「训练营」。⚠️ 不用「开罐」「开始匹配」。
- 好友组队：房号在右，右侧是「确认」。点「确认」进房。房号是否校验 **待定**：现版点确认即进房。
- 点「随机匹配」：进入等待房，并进入选虫页，在选虫页选己方三只虫。
- 好友组队点「确认」：进入等待房，不进选虫页。原两个入口的位置出现「准备」。点「准备」才进选虫页。
- 点「训练营」：不进等待房，直接进选虫页。另外三人已是不动的人机，见 §5.2。
- 旋钮开场可调，局内打开则暂停。

自己练、巢穴测试不在大厅入口里，见 §5。Unity 大厅用训练营，不用自己练。

```
进战页
  ├─ 随机匹配 → 等待房 + 选虫页
  ├─ 好友组队「确认」→ 等待房 →「准备」→ 选虫页
  └─ 训练营 → 选虫页（另外三人已是不动的人机）
选虫页「确定」或倒计时到 0 → 己方已确定
进场 3 秒准备 → 正赛
```

何时进场见联机。随机匹配：倒计时到 0 才进场。训练营：三槽选好点「确定」立刻进场。好友组队：四人都已确定时可提前进场。

### 1.1 未进房 / 等待房

| 状态 | 随机匹配 / 好友组队 | 四人位 + 离开房间 | 「准备」 | 底栏 |
| --- | --- | --- | --- | --- |
| 未进房 | 显示 | 不显示 | 不显示 | 显示，可切页 |
| 随机匹配后 | 隐藏 | 一起出现 | 不显示 | 隐藏，已进选虫页 |
| 好友组队等待 | 隐藏 | 一起出现 | 显示在四人位下方 | 隐藏，不能切页 |

- 「离开房间」：退出等待房，回到未进房，「准备」一并隐藏。
- 等待房仍可点进度条看日勤，仍可点「玩法规则」。
- 好友组队的「准备」点下去才进选虫页。

四人站位 **待定**。本地座位为己方。选虫页另外三人只写头像和「选择中 / 已确定」，不写他们选的虫。己方写头像、同一套状态，以及三槽。见 §2.5。

「返回」离开选虫页，回到进战页。本次三槽不保留；下一次进页三个槽都是空的。

### 1.2 玩法规则

点「玩法规则」弹出说明窗。形式与主界面「活动介绍」相同：遮罩 + 标题 + 正文 +「知道了」。

标题是「玩法规则」，不是「活动介绍」。点「知道了」或遮罩关闭。

### 1.3 日勤

点进度条（蛐蛐新手条 / 宝箱）在当前页弹出日勤，不切页。点「返回」或遮罩关闭。

「领取」只切按钮态：可领 → 已领取。不改进度数字，不改金币、虫卵。不改账号积分，见 [积分与名次](积分与名次_develop_v0.md)。任务档位与数值 **待定**。

## 2. 选虫

选虫页为己方选上场三只精品虫。背包从育虫盘来；三槽决定开局顺序和出圈换虫；绿框标当前槽；点卡入槽；「确定」或倒计时到 0 把己方改成已确定。另外三人只带头像和状态，不露三槽。页上怎么显见 §2.5。

### 2.1 背包从哪来

新名字开档时，背包已有凡品 1-1、1-2、1-3、1-4 各一只。之后每次退出合成（离开育虫盘）时，盘上所有 4 级虫（精品虫）自动收进当前登录名的背包，该格空出。幼虫、中虫、成虫留在盘上，不进背包。

- 合成当时仍把棋子留在盘上，并写入当前登录名的图鉴，见精品虫分册。开档送的四只不写图鉴。
- 背包只列出当前登录名已经收进来的精品虫。换名字看到的是另一份。
- 选虫页不能把虫放回棋盘。

### 2.2 己方三槽

每人上场三只蟋蟀，从左到右为第 1、第 2、第 3 槽。开局用第 1 槽。当前这只出圈后换下一槽，从该玩家开局位再进场；开局位已被圈吃掉时的落点见 [场地与缩圈](场地与缩圈_develop_v0.md) §4。三只都出圈，该玩家出局。四人开局站四角，见该篇 §1。

- 槽里只能是精品虫。
- 槽上写品质、名称、立绘。名称按精品虫分册，已区分性格；性格四字不另写一行。手感在开局时按该分册叠到碰撞量上。
- 同一只虫不能同时占两个槽。
- 空槽不算一只上场虫。人手动点「确定」必须三槽都有虫。倒计时到 0 的补槽见 §2.4。

> 来源：本篇可调配置

| 旋钮 | 键名 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- | --- |
| 每人上场只数 | `livesPerPlayer` | 3 | 1–3 | 己方槽位数；出圈后按槽序换下一只 |

### 2.3 绿框、展开背包、点虫入槽

己方三槽上有一个绿色的方框，标当前槽。点一个位置，绿框移到那一槽。再点背包，就是为当前槽选蟋蟀。

- 进页时绿框在第 1 槽。
- 点某一个槽：绿框移过去。不弹详情、不改槽里已有的虫。
- 选择中点「展开背包」或背包顶栏：己方这一行、背包、「确定」整体上移，盖住另外三名玩家（隐藏）。按钮变成「收起」。
- 点「收起」：己方行、背包、「确定」移回，另外三人重新显示。按钮变回「展开背包」。三槽、绿框、已选的虫、四人状态都不变。
- 背包不是另开一层再关掉。展开时仍可点己方槽换绿框。
- 收起时点栏目无效。
- 已确定时绿框收掉；点「展开背包」无效，见 §7。

背包只列出精品虫。顶栏五个栏目一次只亮一个：

| 栏目 | 列出 |
| --- | --- |
| 全部 | 背包里所有精品虫 |
| 强攻 | 性格为强攻 |
| 灵巧 | 性格为灵巧 |
| 智谋 | 性格为智谋 |
| 耐战 | 性格为耐战 |

展开时栏目为「全部」。点另一个栏目立刻换列表，不改已经入槽的虫。该栏目下一只都没有：列表空，不报错。

⚠️ 切图栏目写「机灵 / 勇猛 / 沉着 / 威严」，品级写「良品 / 优品」，槽上还有「四品」。正文用精品虫分册：性格「强攻 / 灵巧 / 智谋 / 耐战」，品质「凡品 / 灵品 / 仙品 / 极品」。切图按正文改。

背包展开时，点一张卡：这只虫进入当前绿框槽，立刻写上品质、名称、立绘。不弹详情。落到己方当前绿框槽，不落到对手。绿框不自动跳到下一空槽。

- 入槽后这只虫在背包里标成已选，不能再点进别的槽。把槽里的虫换掉之后，被换下来的那只重新可选。
- 点已入槽的那张卡：不变，也不会从原槽挪到当前绿框。

### 2.4 确定与取消选择

四人各自停在「选择中」或「已确定」。进页时己方是选择中。另外三人怎么落到这两态，见 §2.5。

三槽都有虫时，点「确定」：

- 己方变成已确定，三槽锁定，不能再改槽、不能再展开背包。
- 若背包是展开的，先收起。
- 页底按钮改成「取消选择」。
- 不立刻进场。显隐见 §2.5。

未满三槽点「确定」：无效，三槽不变，仍是选择中。

点「取消选择」：己方回到选择中。三槽里已选的虫还在，可以再改槽、再展开背包。按钮改回「确定」。联机同时把己方从已确定改回未确定。

倒计时到 0 之后不能再取消。要在倒计时未到 0 时改槽，点「取消选择」；也可以「返回」离开本页，本次三槽不保留。

随机匹配：点「确定」后停在本页，倒计时到 0 才进战斗，其余三人由人机补齐。训练营：三槽选好点「确定」立刻进战斗，另外三人用进页时那套不动的人机，不再换。好友组队联机：四人都已确定时可以在倒计时未到 0 时进场，见 [联机](联机_develop_v0.md)。

页上有倒计时，从进选虫页起算。已确定后仍减到 0。

> 来源：本篇可调配置

| 旋钮 | 键名 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- | --- |
| 选虫时限 | `selectSeconds` | 59 | 10–120 | 进页后的倒计时秒数 |

到 0 时若己方还是选择中：

1. 已经选好的槽不动。
2. 空槽从背包里尚未入槽的精品虫里随机填入。
3. 不够填的空槽保持空，该玩家少一条命。
4. 若背包是展开的，先收起。
5. 己方变成已确定，三槽锁定，不能再取消。显隐见 §2.5。

到 0 时若已经确定：不再随机，也不能再取消。

开局后这三只按 §2.2 的槽序上场。选虫页选虫到此结束。

### 2.5 选虫页怎么显

页标题是「四人混战」。底栏隐藏。入槽、确定、取消、倒计时补槽见上文。

四人各有头像和状态。状态只有两态：选择中、已确定。另外三人不写他们选的虫，也不出三槽。只有己方写出三槽。

| 状态 | 己方 | 另外三人 | 背包 | 页底按钮 |
| --- | --- | --- | --- | --- |
| 刚进页 | 空槽；绿框在第 1 槽；头像；「选择中」 | 头像 + 「选择中」 | 收着，跟在己方行下 | 「确定」 |
| 选择中、收起 | 有虫的槽写品质和名称；绿框在当前槽；「选择中」 | 头像 + 各人当前状态 | 收着 | 「确定」 |
| 选择中、展开 | 己方行、背包、「确定」上移；绿框仍可点；「选择中」 | 隐藏 | 列出精品虫；当前栏目高亮；已选的卡可辨 | 「收起」 |
| 已确定 | 三槽锁定；绿框收掉；「已确定」 | 头像 + 各人当前状态 | 不能展开 | 「取消选择」 |

倒计时从进页起一直减，见 §2.4。换栏目、入槽、展开 / 收起、确定 / 取消，都立刻换表现。已经入槽的虫不因为换栏目、收起或取消而消失。另外三人换态只换状态文案，不补出三槽。

训练营进页时，另外三人写固定人机名，状态是已确定，仍不写三槽。点上去不改己方三槽。收起时仍显示。展开背包时仍隐藏。场上这三人跑贪蓄 AI，见 §5.2。

联机另外三人的状态跟对方是否已确定走：未确定写「选择中」，已确定写「已确定」。人机补位进页即已确定。

## 3. 开局准备

随机匹配与好友组队进入 3 秒准备：四人都不能蓄力、不能跳。倒计时结束起算正赛 0:00，并开始投放计时。

| 状态 | 能否蓄力 | 计时 |
| --- | --- | --- |
| 准备 | 否 | 不计入正赛 |
| 对局中 | 停稳 | 计入 |
| 暂停 / 打开旋钮 | 否 | 不计入 |
| 出局结算 | 自己不能操作 | 计入（对局继续） |
| 观战中 | 自己不能操作 | 计入（对局继续） |

训练营与随机匹配相同，进入 3 秒准备。自己练、巢穴测试跳过准备，进场即可蓄力。

## 4. 对局结束与观战

仅随机匹配与好友组队出结果页并按名次发放。训练营打完出结果页，不发放。自己练、巢穴测试不结束对局。名次怎么写、发多少，见 [积分与名次](积分与名次_develop_v0.md)。

### 4.1 何时结束

1. 存活玩家只剩 1 人。
2. 几乎同时出圈、场上无人。
3. 硬截止仍有 2 人及以上。
4. 中途有人离开或断线：本局作废。见 [联机](联机_develop_v0.md)。

名次怎么排（出局先后、剩余生命、击杀得分），见 [积分与名次](积分与名次_develop_v0.md) §2。

出圈判定、护盾拉回见 [碰撞逻辑与配置](碰撞逻辑与配置_develop_v1.md) 与 [道具系统](道具系统_develop_v0.md) §5.4。单局 2 分钟、1:30 狂暴、硬截止见道具系统 §2。

HUD：倒计时从 2:00 起算到硬截止；1:30 起标狂暴、场地变色。不弹说明窗。

### 4.2 出局结算

时间还没到硬截止，自己三条命已经用完（三槽都出圈，该玩家出局），且对局还没结束：本机出示出局结算。一只出圈只换下一槽，这个人还在场，不出这层。

对局因为这次出局而结束（场上只剩 1 人没出局，或几乎同时出圈、场上无人）：不出出局结算，直接出结果页，见 §4.4。硬截止到点同样直接出结果页。

出局结算只盖本机。对局不暂停，其余人继续打。自己不能再蓄力、不能跳。这层盖住摇杆。

层上写什么、第 n 名和两项得分怎么来，见 [积分与名次](积分与名次_develop_v0.md) §2 / §5。底栏左「退出」、右「观战」。

| 选择 | 之后 |
| --- | --- |
| 退出 | 本局对自己结束；对手若仍在场则继续；按当时名次发放；回大厅。不再出结果页 |
| 观战 | 收掉出局结算，进 §4.3；对局打到结束再出结果页，按 [积分与名次](积分与名次_develop_v0.md) 发放 |

⚠️ 不再用「继续看 / 退出本局」，也不再为这层暂停整局。出局后点「退出」不是联机的中途离开，本局对其他人继续，不作废。

随机匹配、好友组队、训练营都出这层。训练营排名得分不加进账号，见积分与名次。自己练、巢穴测试不出这层。

### 4.3 观战

观战中自己不能蓄力、不能跳。对局继续计时。

镜头追随当前锁定的一名还没出局的玩家。怎么跟、死区、夹紧，见 [场地与缩圈](场地与缩圈_develop_v0.md) §5。

进观战时默认锁场上还没出局、座位号最小的人（不含自己）。简报未给默认锁谁，策划暂定。

画面下方有「切换视角」。点一次：按座位号往后切到下一个还没出局的人，到末位再回到最小号，跳过自己。可锁对象只有 1 人时，点了仍是这个人。

锁定的人出局：立刻改锁下一个还没出局的人。场上因此只剩 1 人没出局：对局结束，出结果页。

观战仍以本地座位为己方，描边与地面圈不变色。敌方主蟋蟀地面圈用虚线，小蟋蟀用实线。

### 4.4 结果页

自己没出局打到结束，或出局后选了「观战」打到结束：本机出结果页。点「退出」不走结果页，见 §4.2。名次、账号积分与发放见 [积分与名次](积分与名次_develop_v0.md)。

## 5. 人机、训练营、自己练、巢穴测试

人机只在随机匹配 / 好友组队里补对手。训练营走大厅「训练营」入口，另外三人始终是同一套不动的人机。自己练和巢穴测试不在大厅入口里，跳过选虫锁定进场、开局 3 秒和胜负结算。

### 5.1 人机

空位是否补人机 **待定**。补人机时对手用「贪蓄」。共用停稳、耐力、跳跃公式。人机自己选方向并按住计时，不读玩家摇杆反转。

决策顺序：

1. 贴边且仍向外滑 → 短跳拉回。
2. 否则有概率抢近处限时道具（狂暴中只看护盾）或饲料球。
3. 否则瞄准对手偏出圈方向。
4. 不预判小蟋蟀，不绕障。

> 来源：代码常量（不进面板）

| 旋钮 | 键名 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- | --- |
| 蓄力倍率 | `chargeMul` | 1.2 | — | 对人蓄力时长的倍率 |
| 思考间隔 | `react` | 0.28 s | — | 松手后至下一次决策 |
| 预判位移 | `lead` | 0.22 | — | 瞄准对手时的位移提前量 |

巢穴测试对手为木桩，见 §5.4。

### 5.2 训练营

玩家自己选己方三槽。另外三人是固定人机：进页就在、已确定。选虫页只写头像和「已确定」，不写他们的三槽。不换成真人，不随再进页改虫。场上跑和联机补位相同的确定性 AI。上场三槽仍按下表。

| 人机 | 名称 | 三槽 |
| --- | --- | --- |
| 第 1 | 机器人1 | 凡品强攻 ×3 |
| 第 2 | 机器人2 | 凡品灵巧 ×3 |
| 第 3 | 机器人3 | 凡品智谋 ×3 |

- 点「训练营」进选虫页，不进等待房。三槽选好点「确定」立刻进战斗，不等倒计时。
- 另外三人用 §5.1 同一套贪蓄 AI，开局仍占四角。时长、缩圈、镜头与随机匹配相同，见 [场地与缩圈](场地与缩圈_develop_v0.md) §6。
- 被撞仍按碰撞滑；出圈仍换下一槽。
- 开局 3 秒后起算正赛。出圈换虫、胜负判定与随机匹配相同。
- 单局 2 分钟（正赛 90 秒 + 狂暴 30 秒）。1:30 末口并全员狂暴，到 2:00 硬截止。开局有效区是 field-0，不跳到 field-2。
- 结果页出示名次，不发放。见 [积分与名次](积分与名次_develop_v0.md)。

### 5.3 自己练

场上仅自己。无倒计时、不计胜负、无人机。不在大厅入口里。HTML 原型保留；Unity 大厅用训练营。

自己出圈：拉回开局位 `(0, -0.38×半深)`，速度清零，护盾与成长保留。对局不结束。自己练不缩圈、不走四角，有效区用最后一档，见 [场地与缩圈](场地与缩圈_develop_v0.md) §6。

房子仍按道具系统投放。场上无敌人时，小蟋蟀做无定向短跳。

### 5.4 巢穴测试

入口为同地址下的巢穴测试页，不在大厅入口里。

- 开场场心已有一栋房子。
- 两只都在场；未控制的那只为木桩，不跳。
- Tab 切换当前控制的蟋蟀。切走的立刻变为木桩，清除当前蓄力，不跳。
- 无倒计时，不按随机匹配 / 好友组队结算胜负。

## 6. 暂停与重开

- 空格暂停 / 继续。局内打开旋钮即暂停。
- R 重开：非联机立即再来一局；联机客机不能重开，须等房主再开。
- 重开对局才回满耐力，并清除成长、场上拾取物与巢穴。

## 7. 无效

- 未登录：不能进本页，回登录页。
- 幼虫、中虫、成虫：不进背包，不能入槽。
- 已选进某一槽的虫：不能再进别的槽；点那张卡不变。
- 已确定：点槽、点卡、点「展开背包」、点「确定」都不变。点「取消选择」除外，见 §2.4。
- 未满三槽：点「确定」不变。倒计时到 0 除外，见 §2.4。
- 倒计时到 0：点「取消选择」不变。
- 收起时点栏目：不变。
- 背包当前栏目为空：点空白处无入槽。
- 对手行：点上去不改己方三槽。另外三人不写出他们选的虫。训练营另外三人的上场虫也不换。
- 一只出圈、还有下一槽：不出出局结算，换槽继续。
- 自己练、巢穴测试：不出出局结算、不进观战。
- 对局已结束：不出出局结算，走结果页。
- 观战中点摇杆、点场地：不蓄力、不跳、不拖镜头。

## 8. 验收

- [ ] 离开育虫盘时，盘上精品虫进背包、该格空出；幼虫 / 中虫 / 成虫仍在盘上。
- [ ] 随机匹配进选虫页；好友组队先等待房，点「准备」才进选虫页；训练营不进等待房，直接进选虫页。
- [ ] 训练营另外三人进页就是机器人1 / 2 / 3，状态「已确定」，不写三槽；点上去不换。上场仍是凡品强攻 / 灵巧 / 智谋各三只。
- [ ] 训练营场上另外三人跑贪蓄 AI；被撞会滑，出圈换下一槽。
- [ ] 训练营倒计时从 2:00 起算，1:30 狂暴并收口，到点硬截止。开局是 field-0，镜头与随机匹配相同。
- [ ] 选虫页见到己方头像、「选择中」、三槽、绿框、「确定」；另外三人只有头像和状态，没有三槽。
- [ ] 点一个槽，绿框移过去；点「展开背包」，己方行连着背包和「确定」上移，另外三人隐藏，按钮变成「收起」。
- [ ] 点「收起」移回，另外三人重新显示；三槽不变。
- [ ] 点一张卡立刻进入当前绿框槽，不弹详情。
- [ ] 「返回」后再进选虫页，三槽为空，己方回到「选择中」。
- [ ] 同一只虫不能占两槽；被换下后可再选；点已入槽的卡不变。
- [ ] 三槽未满时「确定」无效；满三槽后点「确定」：己方「已确定」，绿框收掉，不能再改槽；页底变成「取消选择」。
- [ ] 点「取消选择」：己方回到「选择中」，三槽仍在，可以再改；按钮改回「确定」。
- [ ] 倒计时到 0：已选的保留，空槽从剩余精品虫里随机补，然后已确定，不能再取消。
- [ ] 点「确定」后停在本页；倒计时到 0 才进场（联机四人都已确定时可提前进场）。
- [ ] 开局第 1 槽先上场，出圈换第 2 槽，再换第 3 槽。
- [ ] 进场 3 秒内不能蓄力、不能跳；结束起算正赛。
- [ ] 一只出圈还有下一槽：换槽继续，不出出局结算。
- [ ] 三条命用完且对局未结束：本机出局结算，对局不暂停；层上有「您已出局」、本场名次、排名得分、击杀得分；左「退出」、右「观战」。
- [ ] 这次出局导致只剩 1 人：不出出局结算，直接出结果页。
- [ ] 点「退出」：回大厅，对手继续，本局不作废。
- [ ] 点「观战」：镜头跟锁定的人；下方「切换视角」可换锁定对象；自己不能蓄力。
- [ ] 名称与品级跟精品虫分册一致，不用切图上的「良品 / 优品 / 四品 / 机灵」。
- [ ] 选虫背包只列出当前登录名的精品虫；新档至少有凡品 1-1～1-4。
