## 明确不做

| 不做 | 分册 |
| --- | --- |
| 第二操作键、走路、对局内背包、丢弃 | 对局内约束；选虫页背包见 [对局匹配交互逻辑](对局匹配交互逻辑_develop_v0.md) |
| 空中转向、蓄满自动跳 | 交互 / 耐力 |
| 罐壁弹回 | 出圈；护盾只挡一次 |
| 公网匹配 | 未做；随机匹配现版进选虫页，锁定后不进场 |
| 密码、云同步、公网账号、玩家时装 | [登录逻辑与配置](登录逻辑与配置_develop_v0.md)；十六套立绘仍是品质 × 性格 |

- 检查脚本：`check-physics.js`
