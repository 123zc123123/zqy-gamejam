## 2. 第一场战斗教学

只插在步骤 2 的**第一场训练营**里。正式匹配、好友房、第二场训练营不再上课。

训练营仍是一条命、另外三人是人机、结果页不发账号积分。课上完之前：比赛时钟停、人机不蓄力不跳、不按正赛投放表刷东西。课上完之后：时钟再走，人机恢复训练营原样，投放恢复训练营原样。

### 2.1 何时开课

开场全景、落到己方角、倒计时「你是X色方」和 3-2-1「开罐！」播完，玩家可以蓄力的那一帧，开始第 1 课。

对白盖住时：摇杆不召出、蓄力不计时、人机不动。点完当前句才接受操作。

### 2.2 课表

六课按顺序，上一课过关才开下一课。每一课：一句对白 → 玩家做一个动作 → 过关。

对局内仍然只有摇杆。饲料球、护盾碰到就吃；房子、卵要撞；没有第二键。

#### 第 1 课 · 跳一次

开局已选过拖动方向，本课只按所选分叉，不再解释两套操作。

- 相反方向：老头说点屏幕召出摇杆，往后拖就往前跳；按住越久越远，松手才跳。手指提示往后拖。对白 `dlg.tutorial.battle_jump`。
- 相同方向：老头说点屏幕召出摇杆，往哪拖就往哪跳；按住越久越远，松手才跳。手指提示往前拖。对白 `dlg.tutorial.battle_jump_same`。
- 玩家：停稳后召出摇杆，按所选方向拖出死区，按住超过点跳最短蓄，松手跳出。
- 落到谁：自己这只虫。
- 过关：自己完成一次有效跳跃（不是取消、不是被撞清蓄）。
- 无效：还在飞/滑时按住不计时；位移小于死区没有方向；未满最短蓄松手 = 取消、不跳。见 [战斗交互逻辑](战斗交互逻辑_develop_v0.md)。
- 表现：遮罩只放行战场；摇杆按闲置淡、拖动加深。蓄力必须有下蹲、身后蓄力条、身前虚线与落点圆圈，朝飞出方向。见 [战斗交互逻辑 §3](战斗交互逻辑_develop_v0.md#3-蓄力-ui)。

#### 第 2 课 · 出圈

- 老头说：桌子沿是边。身体出了边算出局。这场每人一条命，出去就没了。
- 玩家：看清有效区沿。不要求自己跳出界。
- 落到谁：场地。
- 过关：对白点完。沿高亮只在这句指引期间，点完立刻停。
- 无效：踩在沿上但仍在区内 = 还没出。投影一出当前有效区才出局，没有回弹。训练营有效区开局就是末档，见 [场地与缩圈](场地与缩圈_develop_v0.md) §6、[碰撞](碰撞逻辑与配置_develop_v1.md) §5。
- 表现：有效区沿用语义「出局边」高亮；高亮结束立刻还原。已在场上的虫、摇杆不改写。

#### 第 3 课 · 吃饲料球

- 老头说：场上那颗是饲料。跳过去碰到就吃，不用再按键。吃了虫变大。
- 系统：在自己前方可跳到的位置放 1 颗饲料球。正赛投放表暂停。
- 玩家：跳到饲料球上，碰撞圆重叠。
- 落到谁：自己这只虫。成长 +1。饲料球消失。
- 过关：吃到这颗教学饲料球。
- 无效：没碰到不算吃。空中、滑行重叠也算吃。见 [道具系统](道具系统_develop_v0.md) §4 / §5.1。
- 表现：饲料球语义「可吃」；吃到短促反馈，体型可辨变大。

#### 第 4 课 · 吃护盾

- 老头说：这个是护罩。碰到就套上。要是被撞出边，护罩会把你拉回来一次，然后碎掉。
- 系统：在自己前方可跳到的位置放 1 个护盾。
- 玩家：跳到护盾上吃掉。
- 落到谁：自己这只虫。身上有护罩。
- 过关：吃到这颗教学护盾。
- 无效：没碰到不算。再吃只刷新持续时间，不叠两层。护盾不改半径和质量。见道具系统 §5.4。
- 表现：护罩可见。本课不强制演示碎罩；碎罩规则仍是出圈时拉回一次。

#### 第 5 课 · 撞房子

- 老头说：小房子不能吃，要撞。撞到掉血，砸开的人当饲主，会孵出帮你打人的小蟋蟀。卵可以踢，不能吃。
- 系统：在自己前方可跳到的位置放 1 栋教学房子，血量 `tutNestHP`（默认 1），一撞即爆。
- 玩家：跳出去撞上房子。
- 落到谁：房子扣血；最后一击者 = 饲主（自己）。
- 过关：房子被自己砸开，然后看完孵化。
- 砸开之后：镜头移到卵和小蟋蟀那边。比赛时钟放行、人机仍冻着、不刷新东西。等场上出现蟋蟀宝宝（或等到 `tutHatchWaitT`）。老头说：卵会孵成宝宝，只帮饲主撞别人。说完镜头回到自己，再进第 6 课。
- 无效：贴着磨、饲料球、护盾、卵、小蟋蟀都不扣房子血。必须有效撞击。见道具系统 §6.2。
- 表现：房子被撞有受击；爆开可见。卵不是拾取物。镜头先看孵化，再回到自己。

#### 第 6 课 · 把人撞出圈得分

- 老头说：正式比赛里击败对手拿积分；尽可能活到最后也能赢积分；另有积分榜给与会豪杰排名。然后让玩家把前面这只撞出去。
- 系统：在自己与出局边之间放一只木桩虫（不蓄力、不跳，一条命）。另外三名人机仍冻结。
- 玩家：跳出去撞木桩，让木桩出圈，且出圈前最后一撞是自己。
- 落到谁：自己加本局击杀分（`killScoreBase` × 连杀，第一次 +10）。木桩出局。自己成长 +1（把人撞出圈也加成长，见道具系统 §5.2）。
- 过关：自己拿到这次有效击杀。
- 无效：撞了没出圈不得分。停稳后木桩自己滑出圈，没人拿分。自己出圈不得分。护盾若挡住木桩出圈，双方分都不变。见 [积分与名次](积分与名次_develop_v0.md) §1。
- 表现：击杀得分在战斗 HUD 上可辨（闪一下或跳字）。木桩出圈按普通出圈。

第 6 课过关 = 六课结束。取消冻结：比赛时钟从 0 再走，另外三名人机恢复训练营，投放恢复。场上残留的教学卵 / 小蟋蟀继续按道具系统 §6 结算，不收回。

第一次场地预告（红圈脉动、「区域即将崩塌！」）时，比赛时钟先停，老头补两句：有效区会往里收，收完外边算出局。说完把还活着的虫拉进下一档内侧，再放行时钟，避免人还站在开局角就被收出口外。只说这一次。玩家继续把这场打完（一条命，输赢都算），然后走村子线步骤 3。

### 2.3 场上怎么显

| 态 | 玩家看见 |
| --- | --- |
| 对白中 | 老头对话框；战场可看；摇杆不召出 |
| 等操作 | 对白收掉或缩成一句提示；遮罩只放行战场；目标物语义高亮（饲料球 / 护盾 / 房子 / 木桩 / 出局边） |
| 过关瞬间 | 高亮关掉；立刻切下一课对白。第 5 课砸开后先看孵化，不立刻切撞人课 |
| 六课结束 | 遮罩和高亮全关；HUD、摇杆、人机、投放恢复训练营 |
| 第一次缩圈预告 | 红圈脉动 + 崩塌条；老头说明场地会往里收。只这一次 |

换课：立刻换新课的高亮。已经吃掉的饲料球 / 护盾、已经砸开的房子不改写、不补回。

倒计时「你是X色方」只在开场 3-2-1 上，上课时不再复读。

### 2.4 过关与无效

- 六课都必须做动作过关，没有跳过。
- 自己在课中出圈：这条命没了，按训练营出局。引导停在当前课，结算点退出仍走步骤 3；**下次用新档才会再上课**。已开档不重上。
- 木桩在第 6 课前出圈：补一只木桩。
- 教学饲料球 / 护盾 / 房子被别人碰到：本课只有自己，人机冻结，不会发生。
- 对白未点完：操作无效。
- 未停稳：蓄力不计时，与正赛相同。

## 3. 买卵后 · 育虫庐

接在步骤 7 之后。不改合成规则，见 [合成](合成_develop_v0.md)。

买完幼虫人还在小铺。对白点完先回村子，再进育虫盘。盘上按「放一只 → 再放一只 → 拖到一起」三步，只教到中虫。

| 课 | 发生 | 玩家必须做 | 对白 |
| --- | --- | --- | --- |
| 回村 | 小铺对白结束 | 点返回 / 关掉小铺 | — |
| 点开育虫 | 村子只放行育虫盘 | 点 `MenuButtonBreeding` | — |
| 放第一只 | 进盘，遮罩金圈 | 点金圈，扣 1 卵，盘上出现幼虫 | 可一句：点中间金圈放幼虫 |
| 放第二只 | 仍遮罩金圈 | 再点一次金圈 | — |
| 合成 | 遮罩松开两只幼虫，允许互拖 | 把一只拖到另一只上，合成中虫 | 可一句：两只一样的拖一起 |
| 收尾 | 合成成功 | 听完即可，不强制再操作 | `dlg.tutorial.breed_done` |

- 落到谁：当前登录名的卵和棋盘。不进背包。幼虫不能卖、不能收入背包。
- 过关：金圈两次各放成一只幼虫；拖合同级且结果是中虫。
- 无效：卵为 0 或盘满，金圈不变。拖到空格只是挪格，不算过关。拖到不同阶段弹回。点幼虫开详情不算过关。
- 表现：与小铺相同，遮罩只放行当前目标（返回、育虫盘按钮、金圈、两只幼虫）。合成完成立刻换中虫外形。
- 结束：收尾对白点完，`tutorialStep` 完结，遮罩全关。不要求合成到精品。

开档自带虫卵，买 1 只后足够放两只。若进盘时盘上已经有两只幼虫，跳过放卵，直接教拖合成。若已经有中虫或更高，跳过合成，直接收尾。

账号第一次把两只成虫合成精品：必出极品。展示收进背包后，老头说这是金色极品、有专属技能。之后的合成按品质权重和保底走，见 [精品虫品质与性格](精品虫品质与性格_develop_v0.md)。对白 `dlg.tutorial.finest_skill`。只说这一次。

## 5. 验收

村子线原清单仍有效。第一场另加：

- [ ] 新档第一场：开罐后先上课，时钟停、人机不跳。
- [ ] 第 1 课：按开局所选方向播对应对白和手指；必须自己跳出一次才进第 2 课。
- [ ] 第 2 课：出局边高亮，点完对白并亮满时长。
- [ ] 第 3 课：只刷 1 颗饲料球，吃到才过；体型可辨变大。
- [ ] 第 4 课：只刷 1 个护盾，吃到才过；身上有罩。
- [ ] 第 5 课：房子要撞不要吃；一撞爆开。镜头先看卵和宝宝，对白讲清帮饲主撞人，再回到自己。
- [ ] 第 6 课：对白讲正式比赛击败对手、活到最后拿积分和积分榜；把木桩撞出圈才过关。
- [ ] 六课结束后时钟和人机恢复；第一次缩圈预告时老头说明场地会往里收，只说一次。
- [ ] 打完点退出走进战页老头三句。
- [ ] 旧档、第二场训练营、匹配、好友房不上这六课。
- [ ] 进小铺先口头介绍皮肤、不打开购买；点完才遮罩幼虫价签。
- [ ] 买卵后对白不结束引导；回村只放行育虫盘。
- [ ] 金圈放两只幼虫，拖到一起得中虫，才播收尾对白。
- [ ] 收尾后遮罩关掉，不再拦大厅。
- [ ] 账号第一次成虫合成精品必出极品；收包后老头说明专属技能，只说一次。之后按权重抽。
