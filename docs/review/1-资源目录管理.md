# 斗蛐蛐 · 资源目录管理

> 读者是美术与程序。本文是资源交接：Scene / Prefab 归属、运行时图路径、替换槽。
> 玩法以 [碰撞逻辑与配置](碰撞逻辑与配置_develop_v1.md)、[战斗交互逻辑](战斗交互逻辑_develop_v0.md)、[道具系统](道具系统_develop_v0.md) 为准。
> 图多为占位。正式图覆盖同名文件，在 Unity 里把引用拖进 Theme / Prefab。
> 摇杆对齐 [prototype-v5](../斗蛐蛐原型/prototype-v5/) 反弹档：`STICK_SIZE=128`、`STICK_VISUAL=38`。原型是 CSS 径向渐变；正式图拖进 Theme。

⚠️ 移动资源只在 Unity 编辑器里做，保留 `.meta`。

## 1. 目录总则

### 1.2 局内蛐蛐

局内蛐蛐走场景引用或 `Instantiate(cricketPrefab)`。骨骼、皮肤、材质和运行时 Prefab 在 `Art/Characters/`；动作在 `Animations/`：

```text
Assets/
├─ Art/Characters/
│  ├─ Rig/                           # 共享骨骼、Sprite Library
│  ├─ Skins/
│  │  ├─ LAYER_NAMES.txt             # 24 个图层名（含 weiba-l / weiba-r）
│  │  ├─ 1-1.psb                     # 骨骼真源 + Default 皮肤
│  │  ├─ 1-2.psb
│  │  └─ …
│  ├─ Materials/
│  ├─ Shaders/
│  ├─ Cricket.prefab                 # 1 个可换皮 Prefab
│  ├─ Cricket_Body.png               # 旧占位，PSB Prefab 接上后可删
│  └─ Cricket_Antenna.png
├─ Animations/Characters/Crickets/   # 一份 Animator + 动作
└─ Scripts/DouQuqu/
```

**一套骨架、一份动画、十六套皮肤。** 运行时只换 Sprite Library 的 Label。

| 放这里                            | 放什么                                                     |
| --------------------------------- | ---------------------------------------------------------- |
| `Art/.../Rig/`                  | `CricketSkeleton.asset`、`CricketSkins` Sprite Library |
| `Art/.../Skins/`                | 各皮肤 PSB（图层名与 `1-1.psb` / LAYER_NAMES 一致）        |
| `Art/Characters/Cricket.prefab` | 带 Sprite Skin + Sprite Resolver 的那一份 Prefab           |
| `Animations/.../Crickets/`      | `Cricket.controller` 和 Idle / Charge / Jump 等 clip     |

新皮肤：`Assets/Art/Characters/Skins/<Id>.psb`，`<Id>` 用编号<品质>-<性格>（1-1,1-2）。16 套齐了再在 Sprite Library 里加 Label。

换皮约束：图层名、数量、前后顺序与 `Skins/LAYER_NAMES.txt` 一致；只改像素。身体比例靠近 Default。骨骼只在 Default 上改，其它皮肤勾选同一份 Skeleton Asset。

生成共享骨骼（只做一次）：

1. 选中 `Skins/1-1.psb`，Character Rig 已开。
2. 在 `Art/Characters/Rig/` 创建 Skeleton Asset，拖回该 PSB 的 Skeleton 槽。
3. 新皮肤：Character Rig + 同一个 Skeleton Asset，Skinning Editor 里按共享骨骼生成/拷贝权重。
4. 用 Default 角色 Prefab 做 Sprite Library：每个部件一个 Category，每套皮肤一个 Label。

顶视占位图在 `Resources/Battle/Entities/`。正式骨骼角色以 `Art/Characters/Cricket.prefab` 为准。

## 怎么换

1. 文件放到表里的「放入路径」，覆盖或新建。
2. 在 Unity 里确认导入设置（见各节）。
3. 有 Theme / Prefab 槽的，把新图拖进对应字段。空槽继续用占位。

推荐格式：

| 类型                  | 格式              | 说明                                           |
| --------------------- | ----------------- | ---------------------------------------------- |
| 2D 角色 / 道具 / 摇杆 | PNG，RGBA，正方形 | 透明底。也可用 SVG（项目已装 Vector Graphics） |
| UI 图标               | PNG 或 SVG        | 透明底                                         |
| 地面 / 罐壁           | PNG 贴图或材质    | 地面要能 tile                                  |

PNG 建议 2 的幂（256 / 512 / 1024）。Sprite：`Texture Type = Sprite (2D and UI)`，Mesh Type = Full Rect，Pivot = Center。

Figma 源切放各模块 `Textures/Figma/`，运行时图用同目录正式槽。验收截图放对应模块 `Screenshots/`，文件名加日期或 `Verified` / `Latest`。
