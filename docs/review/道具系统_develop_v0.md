# 斗蛐蛐 · 道具系统与单局时长

本文件管场上拾取物、蟋蟀成长、单局时长，以及场地目标「巢穴」。运动公式以 [碰撞逻辑与配置-v2](碰撞逻辑与配置-v2.md) 为准，这里不另开一套。

拾取物四种：**饲料球**、**增大**、**护盾**、**蓄力强化**。饲料球只加成长层；后三种是限时状态。限时道具只改碰撞 v2 已有的量（半径、质量、$A_1$、$T_{\max}$）；护盾例外，只在出圈时把人拉回一次。碰撞 v2 不再重复饲料球和成长。

另有一类**场地目标**：巢穴（小房子 → 卵 → 小蟋蟀）。它不是限时状态，不占 `itemCap`，规则见 §6。

## 1. 对局与拾取流程

拾取和对局计时分开算，互不触发。

**拾取**

```
身体（碰撞圆心在地面上的投影）与饲料球或限时道具重叠
  → 立刻生效
  → 饲料球：成长 +1（未到上限时）
  → 增大 / 护盾 / 蓄力强化：按各自规则改当前状态
```

**失效**

```
增大、蓄力强化到期：只还原该道具改过的量
护盾到期或被消耗：护罩消失（护盾不改半径和质量）
```

**对局**

```
正赛内一方出圈 → 该方出局，对局结束
小蟋蟀把对方撞出圈 → 同样出局，饲主胜（§6.5）
正赛到点仍无人出局 → 全员进入狂暴（增大 + 蓄力强化，持续到本局结束）
加时继续按表投放饲料球和道具；不新刷房子
硬截止仍无人出局 → 比谁离场地中心更近
```

对局内仍然只有摇杆。饲料球、限时道具和巢穴都没有单独按键，不能丢弃，不能放入背包。砸房子、踢卵、躲小蟋蟀全是跳。

空中或滑行中重叠也算拾取。停稳才能蓄力，道具、狂暴与巢穴都不改这条；未停稳时按住，`chargeT` 不计时。

下文「地面投影」一律指蟋蟀碰撞圆心在地面 XZ 上的位置。

## 2. 单局时长

| 段   | 时间       | 名称       | 结束条件                                         |
| ---- | ---------- | ---------- | ------------------------------------------------ |
| 正赛 | 0:00–1:30 | 正常比赛   | 一方出圈则整局结束；到 1:30 双方仍在场则进入加时 |
| 加时 | 1:30–2:00 | 狂暴       | 一方出圈则整局结束；到 2:00 则比较距中心         |
| 截止 | 2:00       | 比较距中心 | 仍在场内者，地面投影更靠近有效区中心的获胜       |

开局有 3 秒准备。倒计时从准备结束、双方可以开始蓄力的那一刻起算。暂停不计入。

加时不是另一套物理。狂暴 = 给场上所有存活角色同时套用 §5.3 增大和 §5.5 蓄力强化（同一组 `sizeScale`、`chargeScale`），持续到本局结束，不再走个人倒计时。满蓄水平速度 $v_{\max}$ 不变。

### 2.1 正赛

`regTime` 内按 §3 投放饲料球、道具与巢穴。角色通过拾取获得短暂的增大 / 护盾 / 蓄力强化；砸掉房子则按 §6 得到一窝小蟋蟀。

正赛应分出大多数对局。加时是少数局的收束，不是默认体验。

### 2.2 加时（狂暴）

正赛结束双方仍在场内，进入加时：

1. 全员获得蓄力强化，参数与拾取相同：读 `chargeScale`，同时改 $A_1$ 与 $T_{\max}$（见 §5.5）。
2. 全员同时获得增大，参数与拾取相同：读 `sizeScale`。半径 $R$、质量 $m$ 先按当时 `growRate` 算完，再乘这个倍率。
3. 两样都持续到本局结束，不叠乘。若身上已有对应拾取效果，改成狂暴状态，去掉个人倒计时，倍率不变。
4. 饲料球与道具继续按 §3 投放，节奏比正赛后段更密。
5. 护盾不因进入加时而清除，按剩余时间或被消耗结算。
6. 场地尺寸、摩擦、成长层数不因狂暴而改变。质量只因增大倍率改变。
7. 加时不新刷房子。场上残留的房子 / 卵 / 小蟋蟀继续按 §6 结算。

要的观感：人更大、蓄满更快、出手数变密，贴边更亏；满蓄能飞多远仍是原来那一脚。正赛里拾取增大或蓄力强化，等于提前享受一小段狂暴。加时不另开更大倍率。

加时开始需要全场可读：场地光线或沙色变化即可，不要弹说明窗。

### 2.3 硬截止

必须有硬截止。加时仍投放护盾，贴边对峙可以把局拖死。

硬截止时双方仍在有效区内：比较此时地面投影到有效区中心的距离，近者胜。距离相同则比较本局成长层数，再相同则记为平局。

加时期间不收圈。先靠体型变大和出手数变密逼出胜负；若试玩里多数局都拖到比较距中心，再另议收圈。

## 3. 投放节奏

投放前疏后密。试探阶段只放开局那几颗，不补；之后再维持数量、加快节奏。这样正赛内不会过早叠满成长上限。

### 3.1 阶段总表

| 阶段 | 时间       | 饲料球                               | 道具                      | 巢穴                                      | 目的                            |
| ---- | ---------- | ------------------------------------ | ------------------------- | ----------------------------------------- | ------------------------------- |
| 试探 | 0:00–0:20 | 场上`heartStart` 颗，不补          | 不刷                      | 不刷                                      | 先打走位和停稳                  |
| 展开 | 0:20–1:10 | 维持`heartCap`，按 `heartGap` 补 | 按`itemTimes`，先慢后快 | `nestFirstT` 出首栋；整条链最多 `nestCap` | 争体型，道具开始加密，抢房子    |
| 收束 | 1:10–1:30 | 同上                                 | 同上                      | 上一窝清完且过 `nestGap` 才刷下一栋       | 正赛最后一轮争夺                |
| 狂暴 | 1:30–2:00 | 改按`heartGapOt` 补                | 继续刷，新刷只出护盾      | 残留继续，不新刷                          | 全员增大 + 蓄力强化，护盾仍可抢 |

### 3.2 饲料球投放

饲料球是场上拾取物，吃掉见 §5.1，成长见 §5.2。这里只管数量和补货。

| 项              | 默认                              | 说明                                           |
| --------------- | --------------------------------- | ---------------------------------------------- |
| 开局数量        | 4                                 | 键名`heartStart`                             |
| 0:20 起场上目标 | 6                                 | 键名`heartCap`；不足则按间隔补；加时同样维持 |
| 正赛补货间隔    | 7 s                               | 键名`heartGap`；0:20–1:30                   |
| 加时补货间隔    | 5 s                               | 键名`heartGapOt`；1:30 之后                  |
| 停止补货        | 无（打到本局结束）                |                                                |
| 拾取半径        | 0.3                               | 键名`heartR`                                 |
| 刷新禁区        | 距边 1.4，距角色 1.3，球与球 1.25 | 不贴边、不叠虫、球与球不叠                     |

试探阶段不补。0:20 起（含加时）一直补到硬截止，或本局提前结束。地上已有的不收回，加时开始时也不清。

每隔一次补货间隔检查一次：场上数量少于 `heartCap` 才补，每次只补 1 颗。差 2 颗不会一次补两颗，要再等一个间隔。

### 3.3 限时道具投放

按 `itemTimes` 到点投放；已在场上的不收回、不替换。不是「吃掉后再等固定秒」才出下一颗。

场上同时最多 `itemCap` 颗（默认 3）。到点时若已满，这次投放挂起，等有空位再出；有空位时一次最多补到上限。新点避开已有道具（彼此 ≥ 2.0）。

| 次序 | 时间 | 距上一颗 | 池                                   |
| ---- | ---- | -------- | ------------------------------------ |
| 1    | 0:20 | —       | 增大 / 护盾 / 蓄力强化，三种均匀随机 |
| 2    | 0:42 | 22 s     | 与上一颗不同                         |
| 3    | 1:00 | 18 s     | 与上一颗不同                         |
| 4    | 1:14 | 14 s     | 与上一颗不同                         |
| 5    | 1:25 | 11 s     | 与上一颗不同                         |
| 6    | 1:34 | 9 s      | 仅护盾                               |
| 7    | 1:42 | 8 s      | 仅护盾                               |
| 8    | 1:50 | 8 s      | 仅护盾                               |

正赛 5 轮，加时 3 轮。

加时全员已有增大和蓄力强化，这两种再刷没有新信息。正赛结束后新刷出的只出护盾。正赛留下的增大、蓄力强化仍留在地上，可以被捡。

刷新位置比饲料球更远离边缘和角色：

|            | 饲料球  | 道具         |
| ---------- | ------- | ------------ |
| 距有效区边 | ≥ 1.4  | ≥ 2.4       |
| 距存活角色 | ≥ 1.3  | ≥ 3.0       |
| 距饲料球   | ≥ 1.25 | ≥ 1.6       |
| 距其他道具 | —      | ≥ 2.0       |
| 优先区域   | —      | 距原点 6～12 |

不贴边刷新，避免为拾取而主动出圈；不贴角色刷新，避免谁离得近谁先捡。有效区是圆角矩形，角落可站的宽度更窄，不要刷在角上。

人机会抢饲料球和道具，也会拦截正在接近拾取物的对手。残血房子应去争最后一击；卵在场上时可以把卵踢向场外。

### 3.4 巢穴投放

巢穴单独投放，不进增大 / 护盾 / 蓄力强化的随机池，不占 `itemCap`。整条链（房子或卵或小蟋蟀）算 1 个巢，场上同时最多 `nestCap`（默认 1）。

试探期不刷。`nestFirstT`（默认 25 s）到点且场上没有巢，刷出一栋小房子。之后只有上一窝的房子、卵、小蟋蟀全部消失，再等 `nestGap`（默认 12 s），才刷下一栋。加时到点也不新刷。

刷新禁区对齐限时道具：距有效区边 ≥ 2.4，距存活角色 ≥ 3.0，距饲料球 / 限时道具 / 其他巢相关物 ≥ 1.6。优先带距原点 6～12。不贴边、不贴人、不刷在圆角死角。

饲料球与限时道具补点时，同样避开场上的房子和卵（≥ 1.6）。小蟋蟀不占刷新禁区。

地上已有的房子 / 卵 / 小蟋蟀，加时开始时不收回。

## 4. 拾取判定

饲料球和限时道具同一套判定：只看地面 XZ，不看高度。虫的碰撞圆与目标碰撞圆相交即拾取。空中或滑行中重叠也算。

| 拾取物   | 半径 | 键名       |
| -------- | ---- | ---------- |
| 饲料球   | 0.3  | `heartR` |
| 限时道具 | 0.45 | `itemR`  |

半径不同，只为场上体量好认。

同一帧同时碰到饲料球和限时道具时，两样都结算，先饲料球后道具。因此同一帧既吃饲料球又吃增大时，先加成长层，再在新的半径、质量上乘增大。

房子、卵、小蟋蟀都不是拾取物。默认（`babyCanLoot` 关）下，卵和小蟋蟀的碰撞圆不参与拾取判定：玩家可以从它们身上捡饲料球和限时道具。规则见 §6.6。

## 5. 拾取物效果

饲料球给蟋蟀成长 +1，没有到期。后三种到期时，只还原该道具改过的量；其余道具和蟋蟀成长不变。护盾不改半径和质量，到期或被消耗时只是护罩消失。

同一种限时道具再次拾取：不叠层，只刷新持续时间。狂暴提供的增大、蓄力强化与对应拾取视为同一种，不叠乘。

### 5.1 饲料球

- 碰到就吃掉。
- 吃一颗，蟋蟀成长加一层。算法见 §5.2。
- 吃饲料球不会附带增大、护盾或蓄力强化。

### 5.2 蟋蟀成长

- 成长只让这只蟋蟀变大、变重。

#### 成长层数growLevel

- 当前层数记为 `growLevel`，开局为 0。
- 来源：
  - 吃一颗饲料球加一层。
  - 把对手撞出圈也加一层。谁把他撞出去，谁加。
  - 己方小蟋蟀把对手撞出圈：记饲主，饲主加一层。不记小蟋蟀。
- 上限：读 `growMax`。
- 已经到顶时，再吃饲料球或再把人撞出圈，饲料球照样消失，层数不再增加。

#### 成长效果

- 根据成长层数，按比例放大蟋蟀半径与质量。
- 放大比例为 `growRate`，每增长一层，比例放大growPerRate：growRate=1+growLevel×growPerRate

$$
R = R_0 \times \texttt{growRate} = R_0 \times (1 + \texttt{growLevel} \times \texttt{growPerRate})
$$

$$
m = m_0 \times \texttt{growRate}
$$

- 每一层都加在开局体型上，不是吃一层就在当前体型上再乘一次。
- 成长不改蓄力快慢，也不改满蓄能飞多远；自己跳出去的速度不变。

#### 清除时机

- 被撞或进入狂暴，都不会清掉成长。
- 出局或本局结束，成长作废。

### 5.3 增大

- 拾取后持续 `sizeT`。
- 当前半径和质量同时乘 `sizeScale`: 这里 $R$、$m$ 取生效时已含成长的当前值。

$$
R' = R \times \texttt{sizeScale},\qquad m' = m \times \texttt{sizeScale}
$$

- 吃饲料球：先加 `growLevel`，再乘仍在生效的 `sizeScale`。对撞分速度、重叠推开都用新质量。
- 加时狂暴使用同一倍率，持续到本局结束。

- 拾取到期后，$R$、$m$ 回到当前 `growRate` 对应的值，不是回到开局。

- 速度不瞬间修改。若缩小后与对手重叠，按碰撞 v2 的质量比推开。狂暴结束即本局结束，不必还原。

### 5.4 护盾

持续 `shieldT`，或被消耗，以先发生者为准。

效果：挡一次出圈。不减少碰撞冲量，不改变质量与摩擦。护盾不是墙：平时不挡碰撞，也不挡出圈判定；只在即将出局的那一下把人拉回区内一次。

地面投影刚越出有效区（碰撞 v2 的 `arenaSDF > 0`）且护盾仍在时：

1. 护盾消失。
2. 沿有效区法线向内移动中心，直到整只虫的碰撞圆回到区内，并再往里留 0.08（即 `arenaSDF = -(R + 0.08)`）。$R$ 取当时值（含增大与成长）。
3. 速度不变，按当前滑行档的摩擦继续匀减速（碰撞 v2 §3.3）。
4. 不反弹，不拉回场地中心。再次出圈即出局。

持续时间内未出圈，护盾到期消失。护盾仍在时再次拾取：刷新持续时间。已被消耗后再拾取：重新获得一层。

加时道具只刷护盾。带着未碎的护罩进入狂暴，或在狂暴中再抢一层，都合法。

### 5.5 蓄力强化

拾取后持续 `chargeBuffT`。加快蓄满所需时间，蓄满后的水平速度 $v_{\max}$ 不变。加时狂暴使用同一组数，持续到本局结束。

碰撞 v2：$\Delta v_x = A_1 \Delta t$，$v_{\max} = A_1 T_{\max}$。倍率 `chargeScale`（下式里的 $s$）同时改两项。$A_1$、$T_{\max}$ 读碰撞文档，本文件不钉它们的默认值。

$$
A_1' = s\,A_1,\qquad T_{\max}' = T_{\max} / s,\qquad v_{\max}' = A_1'T_{\max}' = v_{\max}
$$

短按保底仍读碰撞 v2 的 `dMin`，本文件不改。蓄力强化只缩短蓄到保底所需的时间。

`chargeScale` 不宜再大：再提高会把 $T_{\max}$ 压得太短，对手难以在蓄力阶段反应。狂暴与拾取共用这个值，加时不要再单独加大。

拾取和到期都不另存一条 0～1 进度，只用已经累计的 `chargeT`，按当前 $A_1$ 重算水平速度：

- 拾取时保留 `chargeT`。$\Delta v_x = \min(A_1'\cdot\texttt{chargeT},\, v_{\max})$。若 `chargeT > T_{\max}'$，立即视为蓄满。
- `chargeBuffT` 到期（仅限拾取，不含狂暴）后 $A_1$、$T_{\max}$ 回到碰撞面板值。`chargeT` 保留。$\Delta v_x = \min(A_1\cdot\texttt{chargeT},\, v_{\max})$。若此前是靠缩短后的 $T_{\max}'$ 才达到满蓄，到期后可能回落到未满。
- 进入狂暴：套用与拾取相同的 `chargeScale`，直到本局结束。

## 6. 巢穴（房子 / 卵 / 小蟋蟀）

正赛中段的场地目标。砸掉房子的人成为饲主，得到一小波会自己蹦的小蟋蟀，用来打断和推人。操作仍只有摇杆。

### 6.1 一条链

```
空场 → 刷小房子（nestHP 血）
     → 玩家撞击扣血；最后一击者 = 饲主
     → 房子爆开，散落 nestEggN 枚卵（饲主不变）
     → eggHatchT 后孵成小蟋蟀，只打非饲主
     → 出圈或满 babyLifeT 消失
     → 房子、卵、崽全部清干净后，等 nestGap，再刷下一栋
```

场上同时只走这一条链，整条链算 1 个巢。

### 6.2 小房子

- 血量读 `nestHP`（默认 4）。只有玩家蟋蟀的有效撞击扣 1 血。卵、小蟋蟀、饲料球、限时道具都不扣血。
- **一次有效撞击 = 一次扣血**，不是每个物理子步都扣。有效撞击：相对接近（$v_n < 0$）且双方刚从分离进入接触。同一只必须先离开碰撞再撞上，才能再扣。贴着滑、已经重叠磨着，都不连扣。
- 同一帧两人都打到最后 1 血：比这一下的法向接近速度，大的成为饲主；完全相同则卵无主（见 §6.5）。
- 房子不位移。质量读 `nestMass`（默认 3.0），走碰撞 v2 的弹性碰撞：人被弹开、蓄力打断，房子原地掉血、裂开。
- 房子不挡出圈判定，不是第二圈墙。
- 外形四档必须一眼能数：完好 → 裂 → 塌 → 骨架。最后一击有全场可见的爆开，不靠头顶数字。

### 6.3 卵

最后一击结算当下：

1. 房子消失。
2. `nestEggN` 枚卵（默认 5）在整块有效区内各自随机落点，不围着房子。落点钳在有效区内，并再往里留一个卵半径。卵不能直接刷出圈。
3. 出现后初速为 0；之后仍可被玩家撞飞，走现有地面摩擦刹停。`eggScatterV` 不再用于爆开散落。
4. 每枚卵**自己**倒计时，从爆炸帧起算，互不等待。基准读 `eggHatchT`（默认 3 s），再加 `i × eggHatchGap`（默认 0.28 s）和少量随机 `eggHatchJitter`，打乱分配到各卵。因此不会同一帧一起孵出。到点在**当前所在位置**孵化；还在滑也孵。

3 秒内：

- 玩家可以撞飞卵（轻质量弹性碰撞，质量读 `eggMass`）。**饲主不变。**
- 不能砸碎，不能改归属。
- 卵出圈：该枚消失，少孵一只。
- 卵之间不互撞。
- 卵不吃饲料球、不吃限时道具；碰撞圆不参与拾取判定。
- 头顶一条胶囊：满→空表示剩余孵化时间。全程同样粗；最后约 1/4 只变亮。不写数字。

### 6.4 小蟋蟀

不另开跳跃公式。沿用碰撞 v2 同一条链，只把量缩小。

| 项 | 规则 |
| -- | ---- |
| 敌人 | 只打对方玩家。不打饲主、房子、卵 |
| 无主卵孵出 | 两边都打 |
| 半径 | 开局 `BUG_R` × `babyRScale`（默认 0.40） |
| 质量 | 读 `babyMass`（默认 0.35），不吃饲主成长 |
| $A_1$ | 当前面板 $A_1$ × `babyA1Scale`（默认 0.40） |
| 每次自动蓄 | `babyChargeT`（默认 0.16 s）；短于保底仍走碰撞 v2 的 `dMin` |
| 攻击冷却 | 起跳当下进入 `babyAtkCd`（默认 0.8 s），倒计时含空中和滑行。冷却未完不蓄力、不跳。孵化后第一跳没有冷却 |
| 循环 | 落地且水平速度 $< 0.06$ 且冷却结束 → 自动蓄 `babyChargeT` → 朝敌人此刻地面位置起跳。空中不转向。不预判、不绕障 |
| UI | 与玩家同一套：下蹲 + 地面红线。方向 = 将要飞出的方向；长度随本次已蓄的 $t$ 涨到 `babyChargeT` 对应跳距。不读交互三档，始终按「现版」计时。线随体型缩小，颜色跟饲主；无主则用中立色。飞出后红线消失。头顶另有一条胶囊：满→空表示剩余寿命；满时浅色，少时变红。全程同样粗。不写数字 |
| 碰敌人 | 现有弹性碰撞。质量轻，主要是打断蓄力 + 侧向轻推 |
| 碰饲主 | 穿过，不结算 |
| 碰友方崽 | 碰撞圆不重叠：按质量比推开并换法向速度。不打断蓄力，不记击杀，不打提示 |
| 寿命 | 孵化起算 `babyLifeT`（默认 8 s） |

死亡只有两种，先到先死：

1. 地面投影出有效区（与玩家同一套 `arenaSDF > 0`）
2. 孵化后满 `babyLifeT`

被玩家撞飞但未出圈，仍活着。死后消失，不掉东西，不加成长。

护盾对小蟋蟀打出的出圈生效：仍按 §5.4 拉回一次并碎掉。

### 6.5 归属、击杀、成长

| 事件 | 结算 |
| ---- | ---- |
| 砸房子未碎 | 无奖励，只改房子外观 |
| 砸掉最后 1 血 | 该玩家成为这窝饲主；全部卵归他 |
| 同帧抢碎最后 1 血且法向速度相同 | 卵无主；孵出来打双方 |
| 小蟋蟀把对方撞出圈 | 对局结束，饲主胜；`lastHitId` 记饲主，饲主按 §5.2 加成长 |
| 小蟋蟀自己出圈 | 只死一只，不影响对局 |
| 卵出圈 | 少孵一只 |
| 出局或本局结束 | 房子、卵、小蟋蟀全部清除 |

饲主 3 砸、对手 1 砸抢走——按最后一击算，不按伤害分成。用外形裂开把「只剩 1 血」打满，让抢尾刀是读得懂的博弈。

### 6.6 拾取开关

`babyCanLoot` 默认关。

- **关：** 小蟋蟀不吃饲料球、不吃限时道具；碰撞圆不参与拾取。
- **开：** 只允许吃饲料球。结算在那只小蟋蟀身上：半径 / 质量按 `growPerRate` 加一层，上限仍 `growMax`。**不加饲主成长层。** 增大 / 护盾 / 蓄力强化仍只有玩家能吃。

第一版按关验收。不要为这个开关做两套投放。

### 6.7 自己练

房子仍按 §3.4 刷。最后一击归自己。场上无敌人时，小蟋蟀做无定向短跳，仍按出圈或满 `babyLifeT` 消失。玩家自己出圈仍拉回。

---

## 7. 叠加与清除

三种限时道具可以同时存在，每种最多一层。狂暴的增大、蓄力强化与对应拾取同种，不叠乘。巢穴不是限时状态，不与这三种叠层。

被撞打断只清除蓄力进度，不清除道具，也不取消狂暴，也不清巢穴归属。出局或本局结束时，身上的道具全部清除，场上的房子 / 卵 / 小蟋蟀也全部清除。

---

## 8. 计算顺序

先按 `growRate` 算出玩家的 $R$、$m$，再乘增大（拾取或狂暴），再拿去对撞（含房子、卵、小蟋蟀）、做出圈判定、做护盾拉回。小蟋蟀自己的 $R$、$m$ 只读 §6.4，不乘饲主的成长和增大。

## 10. 设计约束

- 拾取没有额外按键，不能丢弃，不能进背包。巢穴同样没有第二键。
- 饲料球只加成长层，不加限时状态；限时道具不加成长层。不要再做「拾取后加成长层」的限时道具。`babyCanLoot` 打开时，成长只加在那只小蟋蟀上，不加饲主。
- 效果不跨局保留。
- 护盾不减免冲量，不是墙，不反弹，不拉回场地中心。小蟋蟀打出的出圈同样走这一条。
- 蓄力强化必须同时提高 $A_1$ 并缩短 $T_{\max}$，以保持 $v_{\max}$ 不变。只改其中一项会改变满蓄距离。
- 狂暴与拾取共用 `sizeScale`、`chargeScale`，加时不另开更大倍率，不另改摩擦，不收圈。
- 狂暴的增大与蓄力强化不和拾取叠乘。
- 场上饲料球不超过 `heartCap`，限时道具不超过 `itemCap`，巢不超过 `nestCap`。满了不收回旧的，也不再往地上堆。
- 加时新刷出的道具不含增大、蓄力强化，也不新刷房子。
- 贴图和特效不改 $A_1$、质量、摩擦。体型变化只走半径、质量公式。
- 巢穴不是限时状态，不占 `itemCap`。小蟋蟀不另开跳跃公式。
- 小蟋蟀死亡只有出圈或满 `babyLifeT`。被撞飞但未出圈不算死。
- 小蟋蟀把人撞出圈，击杀与成长记饲主，不记小蟋蟀。
- 卵能踢、不能碎、不能改归属。
- 小蟋蟀之间不能重叠；挤开时不打断蓄力、不记击杀。仍穿过饲主。
- 小蟋蟀两次起跳之间至少隔 `babyAtkCd`；孵化后第一跳没有冷却。

表现上不依赖头顶文字。饲料球：场上就是一颗球，吃掉短促反馈即可。增大与狂暴体型：体积可辨。护盾：身上有罩，破碎时场上可见。蓄力强化与狂暴：同样按住一段时间，蓄力指示涨得更快；蓄满后指示长度与没拿该道具时的满蓄相同。狂暴另加全场环境变化，与个人拾取区分。房子：四档破损外形 + 爆开。卵：和饲料球要能分开；头顶胶囊满→空表示剩余孵化时间。小蟋蟀：明显小于玩家；蓄力时必须有下蹲和红线，禁止隐形蓄力；头顶胶囊满→空表示剩余寿命，满时浅色、少时变红。卵的胶囊最后约 1/4 只变亮。不写数字。
