# 斗蛐蛐 · 资源替换

当前工程里的图、颜色、CSS 圆都是**临时占位**。正式美术到位后，按本表替换，尽量只换资源、不改玩法代码。

摇杆交互对齐 [prototype-v5](斗蛐蛐原型/prototype-v5/) 的反弹档：`style.css` 的 `#stick` / `#stick-base` / `#stick-knob`，`game.js` 里 `STICK_SIZE=128`、`STICK_VISUAL=38`。原型**没有摇杆贴图**，是 CSS 径向渐变。Unity 占位用同一套色和尺寸；正式图拖进 Theme 即可。

---

## 1. 局内蛐蛐资源目录与加载方式

当前 Game Jam 项目的局内蛐蛐资源暂时不需要动态加载，也不建议放进 `Resources`。蛐蛐资源应按“美术资源、动作资源、运行时 Prefab、战斗逻辑”分开管理：

```text
Assets/
├─ Art/Characters/Crickets/          # 贴图、骨骼、Sprite、材质
├─ Animations/Characters/Crickets/   # Unity 2D Animation 动作和 Animator
├─ Prefabs/Characters/Crickets/      # 可直接生成的蛐蛐 Prefab
└─ Scripts/Gameplay/Cricket/         # 蛐蛐战斗逻辑
```

局内优先通过场景直接引用，或在管理器、配置对象的序列化字段中拖入蛐蛐 Prefab；需要生成时使用 `Instantiate(cricketPrefab)`。Prefab 对 2D Animation 贴图、骨骼和动作资源的引用属于编辑器引用，不属于动态加载。

只有在蛐蛐种类或皮肤需要按配置 ID 临时选择、资源需要分包/远程更新，或资源量大到必须按需下载时，才考虑 `Resources` 或 Addressables。当前阶段先不要建立 `Resources/Crickets`。

---

## 怎么换（通用）

1. 文件放到表里的「放入路径」，覆盖或新建。
2. 在 Unity 里确认导入设置（见各节）。
3. 有 Theme / Prefab 槽的，把新图拖进对应字段。空槽 = 继续用占位。
4. 不要改 `DouQuquRules`、各 System、MatchController。

推荐格式：

| 类型 | 格式 | 说明 |
| --- | --- | --- |
| 2D 角色 / 道具 / 摇杆 | **PNG，RGBA，正方形** | 透明底。也可用 SVG（项目已装 Vector Graphics） |
| UI 图标 | PNG 或 SVG | 透明底 |
| 地面 / 罐壁 | PNG 贴图 或 材质 | 地面要能 tile |

PNG 建议 2 的幂（256 / 512 / 1024）。Sprite：`Texture Type = Sprite (2D and UI)`，Mesh Type = Full Rect，Pivot = Center。

## 2. 摇杆（优先）

**代码接口**

- 资源槽：`Assets/Art/DouQuqu2D/Stick/DouQuquStickTheme.asset`
- 脚本：`DouQuquStickTheme.cs`（两个 `Sprite`：底盘 / 杆头）
- 绑定：战斗场景 `DouQuquDemoRuntime` → `DouQuquTouchInput.theme`
- 换皮：改 Theme 上的 Sprite 后，运行时 `ApplyTheme()` 会自动用图；不必改 UXML

**放入路径（新建这些文件名即可）**

| 槽 | 放入 | 建议像素 | 原型参考 |
| --- | --- | --- | --- |
| 底盘 `baseSprite` | `Assets/Art/DouQuqu2D/Stick/Stick_Base.png` | 256×256 或 512×512 | 128px 圆盘，金边 `rgba(196,165,116,.4)`，深褐径向 |
| 杆头 `knobSprite` | `Assets/Art/DouQuqu2D/Stick/Stick_Knob.png` | 128×128 | 52px 陶色圆头 |

两张都空着时：USS + Theme 里的占位色，观感接近原型。只换其中一张也可以。

**尺寸（相对竖屏短边，且不超过短边 20%）**

| | 反弹 |
| --- | --- |
| 底盘 | 88 |
| 杆头 | 36 |
| 头可移动半径 | 26 |
| 位置 | 点哪召出 |
