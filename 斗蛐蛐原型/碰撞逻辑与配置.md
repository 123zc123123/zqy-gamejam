# 斗蛐蛐 · 碰撞逻辑与配置

对照代码：`game.js` + 旋钮面板。只写现在原型在跑的规则。

下文数字按默认沙算：`μ = 0.5`，`g = 18`，所以 `μg = 9`。

---

## 1. 一条链路

```
按住蓄力
  → 松手得到物理速度 v
  → 用摩擦算出该飞多远 D = v² / (2μg)
  → 用固定时长把这段距离播完（速度线性降到 0）
  → 撞上时用「本段开始时的物理速度」做完全弹性换速
  → 双方用新速度再算一段 D，用被撞滑行时间播完
```

全程有两套速度：

| 套                             | 存在哪                            | 管什么                   |
| ------------------------------ | --------------------------------- | ------------------------ |
| **物理速度** `physV`   | 起跳 / 被弹开的瞬间写入，碰撞用它 | 飞多远、撞多重           |
| **播放速度** `vx / vz` | 为了在固定时间内走完`D`         | 屏幕上飞多快、位移何时停 |

**飞多远只由物理速度和摩擦决定。** `jumpT` / `hitT` 只改这段距离用几秒播完，不改距离本身。

位置积分只用播放速度。碰撞不用播放速度。

## 2. 主动碰撞前：初始速度与滑行距离

### 2.1 蓄力与初始速度

蓄力控制初始速度。初始速度与蓄力时长成线性关系。蓄力力度在此意为，初始速度增长快慢的系数，vRate。

我们控制**不同重量的蛐蛐，初始速度增长快慢相同**。同一蛐蛐在不同摩擦系数的地面，初始速度增长快慢相同。

蓄力得到的是速度，不是冲量。质量不进起跳：

```
Δv      = vRate × clamp(t, 0, T_max)
```

### 2.2 飞出之后、滑行距离

起跳后立刻进入滑行播完：

```
D            = v² / (2 μ g)     （至少是 0；短按被 dMin 托住）
T            = jumpT            （自己跳）或 hitT（被撞后）
v_播放起点   = 2D / T
```

之后 `T` 秒内，物理速度和播放速度都从各自起点线性降到 0：

```
k = 剩余时间 / T        （开始是 1，结束是 0）
physV = 起点物理速度 × k
vx    = 起点播放速度 × k
位置  += vx × dt
```

`T` 下限被钳在 `0.08 s`。速度太小（`< 1e-5`）则直接清零，不滑。

| 想改什么       | 谁在管                                | 改 jumpT / hitT 会怎样       |
| -------------- | ------------------------------------- | ---------------------------- |
| 飞多远         | `vRate`、蓄了多久、`μ`、`dMin` | 不变                         |
| 飞多快（观感） | 上面那些再除以`T`                   | `T` 越小，同样距离越「弹」 |
| 空中暴露多久   | `T`                                 | 只改时钟                     |

默认自己跳 `jumpT = 0.4 s`：

| 档               | 物理速度 | 位移 D            | 播放起点 |
| ---------------- | -------- | ----------------- | -------- |
| 短按（< 0.20 s） | 4.65     | **1.2**     | 6.0      |
| 蓄满 0.55 s      | 12.65    | **≈ 8.89** | ≈ 44.5  |

播放速度随 `v²` 涨，碰撞用的物理速度只随 `v` 涨。蓄得越满，观感越快，碰撞并没有同比例变狠。

跳弧是纯表现，不进判定：

```
最高点 = H_MAX × (0.12 + 0.88 × 蓄力比例)
H_MAX  = 0.68
时长   = jumpT
高度   = 4 × 最高点 × u × (1 - u)     （u 从 0 到 1 的抛物线）
```

判定永远拍扁在地面。飞过对方「头顶」也会撞。被撞瞬间高度清零，跳弧取消。

### 2.3保底限制

1. 起跳蓄力时间下限`T_min`：未满松手是否取消。默认配置0，让玩家只要按了就能蓄力。
2. 保底位移`dMin`与最小起跳速度`v_min`

   1. 在蓄力时间很短的情况下，玩家应该可见移动，不应该只是微乎其微的移动。
   2. v_min   = √(2 μ g · dMin)，事实上，保底位移`dMin`与最小起跳速度`v_min`是能相互确定的。
   3. 从表现出发，我们把 保底位移`dMin`作为配置项。
   4. v_起跳  = max(v_min, Δv)

| 项        | 默认   | 含义                                             |
| --------- | ------ | ------------------------------------------------ |
| `T_min` | 0      | 未满松手是否取消                                 |
| `T_max` | 0.55 s | Δv 封顶时间                                     |
| `vRate` | 23     | 每蓄 1 秒加多少物理速度                          |
| `dMin`  | 1.2    | 短按保底**位移**（内部再反推成 `v_min`） |

默认算出来：

- `v_min = √(2 × 9 × 1.2) ≈ 4.65`
- 蓄到保底要 `4.65 / 23 ≈ 0.20 s`
- **短于 0.20 s 的按，全是同一档：飞 1.2**
- 蓄满 `v = 23 × 0.55 = 12.65`，飞 `12.65² / 18 ≈ 8.89`

大虫和小虫同样蓄力，自己飞一样远。质量只在对撞分速度时生效。

细则：

- 按住就开始计时，`chargeT` 和真实时间 1:1。
- 方向 360° 可改；松手后方向锁定，空中不能转。
- 必须停稳才能蓄。还在飞 / 还在滑时按住，只挂起；停稳后才开始计。
- 停稳判定：滑行时钟走完，且播放速度 `< 0.06`。
- 蓄力中被撞：进度清零，不锁操作。手指还按着，停稳后从 0 再蓄。
- 自己跳落地后可以立刻再蓄。
- `T_min = 0`：点一下就跳。`T_min > 0`：松手时未满则取消、不跳。
- 蓄满后 Δv 封顶，可以一直按着，不会自动跳出。

## 4. 碰撞

### 4.1 判定

- 圆 vs 圆，半径 `r`，只看地面 XZ，不管高度。
- 每帧拆 `MOVE_SUBSTEPS = 6` 次：先位移，再碰撞。
- 当前帧已经重叠：先按质量比推开，再结算速度。
- 当前帧没重叠、但这一步相对运动扫过对方：用线段扫圆补一次，把双方拨回接触点再结算。
- 没有罐壁。地面投影超出圆角矩形有效区 = 出局。

### 4.2 用哪套速度去撞

碰撞入射速度不是正在衰减的播放速度，也不是正在衰减的物理速度。

它是 **本段滑行开始时记下的物理速度**，再乘尾段衰减：

```
k    = 剩余时间 / 本段时长
fade = k ≥ 0.15 时为 1；否则为 k / 0.15
入射 = 起点物理速度 × fade
```

- 前 85% 时间：全力，等于起跳或上一次被弹开时的物理速度
- 最后 15%（`ATK_FADE = 0.15`）：线性收到 0
- 已经停稳（滑行时钟走完）：入射 = 0，等于撞静止物

站桩被撞、蓄力被撞，入射都是 0。正在飞的虫在绝大部分航程里都是满速撞击。

### 4.3 换速

完全弹性，`e = 1`。只换法线方向，切线不换：

```
v_n = 相对速度在法线上的分量
若 v_n ≥ 0：已经在分离，不算撞

j = -(1 + e) × v_n / (1/m_A + 1/m_B)

A 的新物理速度 = A 入射 - (j / m_A) × 法线
B 的新物理速度 = B 入射 + (j / m_B) × 法线
```

质量大的少飞，小的多飞。等质量正撞 ≈ 交换法向速度。

重叠推开也按质量比：轻的多让、重的少让。

撞完立刻：

1. 打断双方蓄力（进度清零，不锁操作）
2. 取消跳弧，贴地
3. 用新物理速度重算 `D`，双方都用 `hitT` 播滑行
4. 记下 `lastHitId`；对方出圈则击杀方 +1 成长

被撞飞多远：

```
D_被撞 = v_撞后² / (2 μ g)
```

`hitT` 只改滑行快慢，不改这段距离。

默认例子（等质量、满蓄正撞站桩）：进攻方几乎停住，防守方吃走 12.65，滑出 ≈ 8.89。侧撞只吃法向分量，距离按那个分量的平方掉。

## 5. 出圈、成长、心

- 有效区：半宽 21.2、半深 31.8、圆角 7.2 的圆角矩形。角上有效区更窄。
- 开局两人站在纵轴 ±38% 半深处，间距约 24.2。
- 投影一出有效区就出局，没有回弹。
- 吃心或击杀：成长 +1，上限 6 层。

```
倍率 g = 1 + 层数 × growPer
半径 r = 0.9 × g
质量 m = max(0.08, 基础质量) × g
```

默认 `growPer = 0.16`：满层半径和质量都 × 1.96。大虫更好撞人、更难被推，也更好被瞄、更容易贴边。成长不改自己的起跳速度。

场上 18 颗心，捡取半径 0.3，吃掉后 5.5 s 刷新。刷新点避开边（距边 1.4）和虫（距虫 1.3）。

## 6. 可调配置

### 6.1 面板旋钮

局前可调。局内打开旋钮会暂停。导出 JSON 的键名就是下表「键名」。

| 旋钮           | 键名        | 默认   | 面板范围  | 管什么                                                     |
| -------------- | ----------- | ------ | --------- | ---------------------------------------------------------- |
| T_min 最小蓄力 | `tMin`    | 0      | 0–1 s    | 未满松手取消；0 = 点一下就跳                               |
| T_max 蓄满     | `tMax`    | 0.55 s | 0.25–3   | Δv 封顶时间；蓄满外观                                     |
| 最低跳速(距)   | `dMin`    | 1.2    | 0.2–4    | 短按保底位移；内部换成`v_min`                            |
| Δv / 秒       | `vRate`   | 23     | 2–60     | 蓄力变物理速度的斜率                                       |
| m 质量         | `m`       | 1      | 0.5–2.5  | 只影响对撞谁飞得远，不影响自己起跳                         |
| 跳跃时间       | `jumpT`   | 0.4 s  | 0.15–1   | 自己跳：播完 D 用多久、跳弧时长                            |
| 被撞滑行       | `hitT`    | 0.4 s  | 0.15–1   | 被弹开后播完新 D 用多久                                    |
| μ 地面摩擦    | `mu`      | 0.5    | 0.08–1.8 | 同样 v 滑多远；短按仍钉在 dMin（`v_min` 会跟着 μ 重算） |
| 每心成长       | `growPer` | 0.16   | 0.02–0.5 | 每层半径和质量同比放大                                     |

另外两颗不影响公式：`0.5× 慢放`、`速度线`。

拧一颗会带上另一颗：

1. **改 μ**：蓄满飞得更远或更近；短按距离仍是 `dMin`。
2. **改 jumpT / hitT**：距离不变，只改快慢；满威力撞击窗口永远是时长的最后 15%，绝对时间跟着变。
3. **改 vRate 或 T_max**：蓄满速度、蓄满距离、蓄满观感一起变。
4. **改 m**：同体型 1v1 几乎无感；吃心变大后才明显推得动 / 推不动。

默认验收数：

| 档                   | 物理速度     | 位移 D            | 播放起点（jumpT = 0.4） |
| -------------------- | ------------ | ----------------- | ----------------------- |
| 短按（< 0.20 s）     | 4.65         | **1.2**     | 6.0                     |
| 蓄满 0.55 s          | 12.65        | **≈ 8.89** | ≈ 44.5                 |
| 等质量、满蓄正撞站桩 | 防守方 12.65 | **≈ 8.89** | 由 hitT 播              |

满蓄 8.89，半场约 21，开局间距约 24。一跳到不了对面，出局要靠撞、连跳或吃心变大。

## 7. 四个手感问题

| 问题                       | 现在怎么控                                                                                                       |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **蓄力的速度**       | 时间线性涨。每秒加`vRate` 的物理速度，到 `T_max` 封顶。`T_min` 只决定松手能不能跳。                        |
| **飞出的速度**       | 物理速度 =`max(√(2μg · dMin), vRate · t)`。屏幕上那一下 = `2D / jumpT`，会快得多。                       |
| **飞的过程中的速度** | 从起点线性降到 0，时长`jumpT`（自己跳）或 `hitT`（被撞）。碰撞在前 85% 仍按起点物理速度算，最后 15% 才衰减。 |
| **被撞击的距离**     | 弹性换速得到新`v`，再 `D = v² / (2μg)`。质量比决定新 `v`。`hitT` 不改距离，只改滑行快慢。              |

## 8. 建议调参顺序

1. **先钉位移表**：`dMin`（碎跳）、`vRate` + `T_max`（满蓄）、`μ`（全局远近）。这三格决定一跳多远、一撞多远。
2. **再钉时间感**：`jumpT` 自己跳的节奏，`hitT` 被撞后的可读窗口。距离已经锁死，只改快慢。
3. **最后钉体重**：`m` 和 `growPer`。几乎不改你自己跳多远，只改对撞分配。
4. 要改「一撞出圈率」，优先改位移表或场地大小，不要去拧 `jumpT`。

## 9. 代码锚点

| 行为        | 位置                                                              |
| ----------- | ----------------------------------------------------------------- |
| 默认旋钮    | `DEFAULTS`                                                      |
| 摩擦加速度  | `frictionAccel()` → `μ × G_GROUND`                         |
| 保底跳速    | `jumpSpeedMin()` → 由 `dMin` 反推                            |
| 蓄力 Δv    | `chargeDeltaV()` / `jumpDeltaV()`                             |
| 起跳        | `doJump()` → 写入 `physV`，再 `beginSlide(..., jumpT)`     |
| 滑行播完    | `beginSlide()` → `D = v²/(2μg)`，`vPlay = 2D/T`          |
| 过程减速    | `stepMotion()` → `k = slideT / T`                            |
| 碰撞入射    | `attackVel()` → 起点物理速度 × 尾 15% fade                    |
| 弹性换速    | `bouncePair()` → `e = 1`，随后双方 `beginSlide(..., hitT)` |
| 重叠 / 扫圆 | `separatePair()` / `collide()`                                |
| 成长改体    | `refreshBody()` → `r`、`m` 同比放大                        |
| 出圈        | `markOut()` / `inArena()`                                     |
